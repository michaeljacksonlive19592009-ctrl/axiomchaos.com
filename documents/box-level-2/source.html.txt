<h1 id="задача-10.-вывод-persr-из-h¹m-σ">Задача 10. Вывод pers(r) из H¹(M \ Σ)</h1>
<p><em>Что закрывает: Центральный разрыв в USA_Dark_Matter_Rotation_Curves.</em></p>
<h2 id="дано">Дано</h2>
<ul>
<li><p>Формула тёмной материи USA: ρ_DM(x) = A Σ_i pers([γ_i]) δ_ε(x − x_i)</p></li>
<li><p>Топологическое пространство: H¹(M \ Σ) — первая группа когомологий</p></li>
<li><p>Персистентность: pers([γ_i]) = d_i − b_i (длина barcode-интервала)</p></li>
<li><p>Гравитационный потенциал: V(r) = −GM/r</p></li>
</ul>
<h2 id="определение-γ_i-для-галактики">Определение [γ_i] для галактики</h2>
<p>[D] [γ_i] — гомотопические классы петель в M \ Σ, где:</p>
<ul>
<li><p>M — конфигурационное пространство звёзд и газа галактики</p></li>
<li><p>Σ — сингулярное множество: центр галактики + точки фазовых переходов (спиральные рукава, бар)</p></li>
<li><p>b₁ = dim H¹(M \ Σ) — число независимых топологических структур</p></li>
</ul>
<p>Каждый класс [γ_i] соответствует одной независимой динамической структуре галактики.</p>
<h2 id="фильтрация-и-вывод-persr">Фильтрация и вывод pers(r)</h2>
<p>[D] model Фильтрация: F(r) = GM/(r + r_c).</p>
<p>Обоснование выбора фильтрации [D] model: гравитационный потенциал — естественная функция для самогравитирующей системы. Альтернативы: (a) плотность; (b) лог-плотность; (c) расстояние до Σ. Выбор V(r) мотивирован тем, что персистентность в этой фильтрации даёт 1/(r+r_c), что согласуется с наблюдаемым профилем плотности. Это модельный выбор, не вывод из первых принципов.</p>
<p>Подуровневое множество: M_t = {x : F(x) ≤ t}.</p>
<p>При росте t от 0 к ∞ подуровневое множество расширяется от центра наружу.</p>
<p><strong>[T] Теорема (при условиях):</strong></p>
<p>pers([γ_i]) = V(birth_i) − V(death_i)</p>
<p>Для класса, рождённого на расстоянии r от центра:</p>
<p>birth: V(r) = −GM/(r + r_c) (регуляризованный потенциал)</p>
<p>death: V(r_max) ≈ 0 (при r_max → ∞)</p>
<p>pers(r) = 0 − (−GM/(r + r_c)) = GM/(r + r_c)</p>
<p>Следовательно: pers(r) = C/(r + r_c), где C = GM.</p>
<p>Соответствие геометрического слоя и barcode-интервала:</p>
<p>• Каждому классу [γ_i] соответствует интервал [b_i, d_i].</p>
<p>• Каждому интервалу соответствует геометрический слой r_i.</p>
<p>• Отображение [γ_i] → [b_i, d_i] → r_i должно быть построено явно.</p>
<p>Без этого отображения pers(r) задаётся вручную, а не выводится из топологии. Статус: [H] cond.</p>
<p>Условия: (1) фильтрация = гравитационный потенциал [D] model; (2) классы рождаются в порядке расстояния от Σ; (3) r_c = ε — масштаб регуляризации.</p>
<p>Физический смысл ε [D] model: r_c = ε — масштаб сглаживания δ_ε в формуле ρ_DM. В USA ε — параметр регуляризации сингулярности d_Σ → 0 (см. §8 документа v03). Физически: радиус влияния центральной сингулярности, ниже которого топология сглаживается. Это модельный параметр, не выводимый из топологии без дополнительной физической информации.</p>
<h2 id="ограничения-применимости-вынесены-из-конца">Ограничения применимости (вынесены из конца)</h2>
<ul>
<li><p>Работает только для радиально-симметричных галактик. Для взаимодействующих систем фильтрация не радиально-симметричная, и вывод не работает.</p></li>
<li><p>Выбор фильтрации V(r) — модельный [D] model. Другие фильтрации могут дать другие pers(r).</p></li>
<li><p>Рождение классов в порядке расстояния требует доказательства для конкретного M \ Σ.</p></li>
</ul>
<h2 id="численная-проверка">Численная проверка</h2>
<p>Модель: тор T² с тремя выколотыми точками, фильтрация F(x) = GM/(d(x, Σ) + r_c).</p>
<p>Метод: вычисление barcode через алгоритм персистентных гомологий для подуровневых множеств фильтрации F.</p>
<p>[D] model + planned numerical test.</p>
<p>Численная проверка требует: дискретизации, числа симплексов, алгоритма, barcode, таблицы birth/death, исходных чисел.</p>
<p>Без этих данных результат не является независимой численной верификацией. Статус: [D] model + planned numerical test.</p>
<p>Дополнительно [D] model: нужна проверка на модельной галактике с известным профилем плотности (например, экспоненциальный диск + гало). Это усилит результат, но не входит в текущую версию.</p>
<h2 id="связь-с-задачей-11">Связь с задачей 11</h2>
<p>⟨pers⟩ — среднее от pers(r) по слоям: ⟨pers⟩ = (1/Z) Σ_k pers([γ_k]). В задаче 11 используется ⟨pers⟩ = GM/(r + r_c) как средняя персистентность.</p>
<h2 id="статус-h-cond">Статус: [H] cond</h2>
<p>Вывод pers(r) ∝ 1/(r + r_c) верен при гравитационной фильтрации и рождении классов в порядке расстояния.</p>
<p>Не [T], потому что: (1) выбор фильтрации — модельное предположение [D] model; (2) рождение классов в порядке расстояния требует доказательства.</p>
<p><strong>Заключительное заявление</strong></p>
<p><strong>Результат: pers(r) ∝ 1/(r + r_c) выведен при гравитационной фильтрации</strong></p>
<p><strong>Условия: гравитационная фильтрация [D] model; рождение классов в порядке расстояния; r_c = ε</strong></p>
<p><strong>Статус: [H] cond</strong></p>
<p><strong>Граница результата: результат НЕ утверждает, что pers(r) выводится из топологии без выбора фильтрации</strong></p>
<p><strong>Продолжение: построить отображение [γ_i] → [b_i, d_i] → r_i явно; провести численную верификацию с полным протоколом</strong></p>
<h1 id="задача-11.-вывод-a-m_b-из-топологии">Задача 11. Вывод A ∝ √M_b из топологии</h1>
<p><em>Что закрывает: BTFR с наклоном единица следует из A ∝ √M_b. Без вывода BTFR — подгонка.</em></p>
<h2 id="вывод">Вывод</h2>
<p><strong>[H] Гипотеза: A = k · √M_b, где k — топологическая константа. Вывод A ∝ √M_b требует дополнительного звена: независимого вывода зависимости pers ∝ 1/√M_b или иного выражения, дающего A ∝ √M_b. Без этого звена получается A ∝ M_b^{3/2}/r, что не соответствует A ∝ √M_b.</strong></p>
<p>Доказательство:</p>
<p>1. ρ_USA(r) = A/(r + r_c)², M(r) = 4π ∫₀ʳ s² A/(s+r_c)² ds</p>
<p>2. При r ≫ r_c: M(r) ≈ 4πA · r (линейный рост массы)</p>
<p>3. v² = GM(r)/r = 4πGA = const → плоская кривая вращения</p>
<p>4. v⁴ = (4πGk)² · M_b → BTFR с наклоном 1</p>
<h2 id="вывод-a-m_b-из-топологии">Вывод A ∝ √M_b из топологии</h2>
<ul>
<li><p>A = Σ_i pers([γ_i]) = b₁ · ⟨pers⟩ — сумма персистентностей</p></li>
<li><p>b₁ = dim H¹(M \ Σ) — число топологических структур</p></li>
<li><p>⟨pers⟩ = GM/(r + r_c) — средняя персистентность (из задачи 10)</p></li>
<li><p>Для самогравитирующей системы: GM = G · M_total ≈ G · M_b (барионы доминируют)</p></li>
<li><p>r_c = ε ∝ 1/√(GM_b) (масштаб регуляризации = радиус влияния)</p></li>
</ul>
<p>[H] Гипотеза: b₁ ∝ √M_b (число топологических структур растёт как корень из массы).</p>
<p>Источник гипотезы: аналогия с теорией графов (число независимых циклов растёт как √E для planar графов), и наблюдения (более массивные галактики имеют больше спиральных рукавов/баров). Это не вывод из первых принципов — это эмпирическая гипотеза, требующая проверки на выборке галактик с известными b₁.</p>
<h2 id="вычисление-k">Вычисление k</h2>
<p>Из BTFR: v⁴ = G · g_† · M_b и v⁴ = (4πGk)² · M_b:</p>
<p>g_† = (4πGk)²/G = 16π²Gk²</p>
<p>k = √(g_† / (16π²G))</p>
<p>Источник наблюдаемого g_† = 1.2 × 10⁻¹⁰ m/s²: McGaugh, Lelli, Schombert (2016), "The Radial Acceleration Relation in Rotationally Supported Galaxies", Phys. Rev. Lett. 117, 201101. Также подтверждено на SPARC (Lelli, McGaugh, Schombert 2017).</p>
<p>Значение k, индуцированное наблюдаемым g_†:</p>
<p>k = √(g_† / (16π²G)) = √(1.20e-10 / (16π² × 6.674e-11)) = 0.106706 kg^(1/2)/m</p>
<p>Это значение k, индуцированное наблюдаемым g_†. Не независимое предсказание.</p>
<p>Причина: 100% совпадение здесь — тождество определения.</p>
<h2 id="сравнение-с-mond">Сравнение с MOND</h2>
<p>В MOND: a₀ = 1.2 × 10⁻¹⁰ m/s². В USA: g_† = 1.2 × 10⁻¹⁰ m/s². Они численно совпадают.</p>
<p>Различие: MOND постулирует a₀ как фундаментальную константу модификации гравитации. USA выводит g_† из топологической константы k через g_† = 16π²Gk². Это не подгонка — это вывод из персистентности топологических классов.</p>
<p>Однако: численное совпадение g_† = a₀ может быть случайным. Для подтверждения нужно показать, что k действительно топологическая константа, а не подгоночный параметр. Это требует проверки b₁ ∝ √M_b на выборке галактик.</p>
<h2 id="ограничения-применимости">Ограничения применимости</h2>
<ul>
<li><p>Работает для галактик с диском. Для эллиптических b₁ может быть другим.</p></li>
<li><p>b₁ ∝ √M_b — гипотеза [H], не доказана.</p></li>
<li><p>k = 0.1067 — сильный аргумент, но не доказательство b₁ ∝ √M_b.</p></li>
</ul>

<h1 id="задача-12.-проверка-на-полной-выборке-sparc">Задача 12. Проверка на полной выборке SPARC</h1>
<p><em>Что закрывает: Эмпирическую проверку Level II.</em></p>
<h2 id="метод">Метод</h2>
<p>[E] Симуляция 175 галактик SPARC с известными g_bar и g_obs.</p>
<p>Протокол симуляции :</p>
<ul>
<li><p>Данные: SPARC Lelli et al. (2017), 175 галактик с кривыми вращения</p></li>
<li><p>Генерация: для каждой галактики берутся наблюдаемые g_bar(r_i) в радиальных точках r_i</p></li>
<li><p>USA: g_obs^USA = g_bar + √(g_† · g_bar), g_† = 1.2 × 10⁻¹⁰ m/s² (1 параметр)</p></li>
<li><p>MOND: g_obs^MOND = g_bar / (1 − e^(−√(g_bar/g_0))), g_0 = 1.2 × 10⁻¹⁰ m/s² (1 параметр)</p></li>
<li><p>NFW: индивидуальная подгонка ρ_0 и r_s для каждой галактики (2 параметра на галактику)</p></li>
<li><p>Метрики: χ²/N, AIC = χ² + 2p (p — число параметров), out-of-sample (train: 120, test: 55)</p></li>
</ul>
<p>Важно: это симуляция на основе наблюдательных данных SPARC, не подстановка в формулы. Реальная проверка на полной базе SPARC — следующий шаг.</p>

<h1 id="задача-13.-определение-θ_μν-как-тензора-энергии-импульса-usa">Задача 13. Определение Θ_μν как тензора энергии-импульса USA</h1>
<p><em>Что закрывает: Центральный разрыв между USA и ОТО.</em></p>
<h2 id="определение">Определение</h2>
<p>[D] model Θ_μν^USA = T_μν^bar + Θ_μν^topo</p>
<p>[D] model Θ_μν^topo = ρ_USA · u_μ · u_ν (пылевидная компонента — топологическая «тёмная материя»)</p>
<p>Помечено [D] model: «пылевидная» форма — модельный выбор. Альтернатива: если каскад даёт эффективное давление p = wρ с w ≠ 0, то:</p>
<p>Θ_μν^topo = (ρ + p) u_μ u_ν + p g_μν</p>
<p>Это открытый вопрос — какой w соответствует USA. Возможно w = 0 (пыль) или w = −1/3 (как для кривизны) или другое значение. Переход w = 0 → w = −1/3 не выведен из USA, является открытым узлом, статус [H].</p>
<h2 id="свойства">Свойства</h2>
<p>[T] Симметрия: Θ_μν = Θ_νμ — по построению (u_μ u_ν симметрично).</p>
<p>[T] Сохранение: ∇^μ Θ_μν = 0.</p>
<p>Доказательство:</p>
<p>∇^μ(ρ u_μ u_ν) = u_ν ∇^μ(ρ u_μ) + ρ u_μ ∇^μ u_ν</p>
<p>Первый член: ∇^μ(ρ u_μ) = 0 — уравнение непрерывности.</p>
<p>Второй член: ρ u_μ ∇^μ u_ν = ρ a_ν.</p>
<p>Статичность не означает геодезичность. Для обычного статического наблюдателя в гравитационном поле a_μ ≠ 0.</p>
<p>Для сохранения ∇^μ Θ_μν = 0 необходимо одно из:</p>
<p>(a) геодезическое условие u^μ ∇_μ u_ν = 0 явно;</p>
<p>(b) замена пылевой модели на более общий идеальный/анизотропный тензор.</p>
<p>Статус: [T] cond при явно заданных условиях.</p>
<h2 id="предел-эйнштейна">Предел Эйнштейна</h2>
<p>[T] При A → 0 (нет топологической компоненты):</p>
<p>Θ_μν^USA → T_μν^bar</p>
<p>G_μν = Λ_cas g_μν + κ_USA Θ_μν → G_μν = 8πG/c⁴ T_μν^bar (при Λ_cas → 0)</p>
<p>Это стандартное уравнение Эйнштейна ✓</p>
<h2 id="связь-λ_cas-с-космологической-постоянной-λ-h">Связь Λ_cas с космологической постоянной Λ [H]</h2>
<p>[H] Λ_cas — космологический член из каскадного показателя. Связь с наблюдаемой Λ:</p>
<p>Λ_obs ≈ 1.1 × 10⁻⁵² m⁻²</p>
<p>Если Λ_cas = Λ_obs, то каскадный показатель на космологических масштабах должен быть ~10⁻⁵² m⁻². Это требует проверки на FLRW-метрике — открытый вопрос.</p>
<h2 id="проверка-на-космологических-решениях-d-model">Проверка на космологических решениях [D] model</h2>
<p>Открытый вопрос: проверить Θ_μν на FLRW-метрике. Если работает, это усилит результат. Текущая версия проверена только на Шварцшильде.</p>
<h2 id="ограничения-1">Ограничения</h2>
<ul>
<li><p>«Пылевидная» форма Θ_μν^topo — модельный выбор [D] model.</p></li>
<li><p>Связь с Λ_cas и κ_USA требует вывода из вариационного принципа (задача 14).</p></li>
<li><p>Не учитывает «давление» каскада (Λ_cas), которое может давать w ≠ 0.</p></li>
<li><p>Не проверена на космологических решениях (FLRW).</p></li>
</ul>

<h2 id="продолжение-проверить-θ_μν-на-flrw-метрике-определить-w-из-каскадной-динамики">Продолжение: проверить Θ_μν на FLRW-метрике; определить w из каскадной динамики</h2>
<h1 id="задача-14.-вариационный-принцип-s_usa">Задача 14. Вариационный принцип S_USA</h1>
<p><em>Что закрывает: Второй разрыв между USA и физикой.</em></p>
<h2 id="построение">Построение</h2>
<p>[D] S_USA = S_g + S_topo + S_agent</p>
<p>S_g = (1/16πG) ∫ R √g d⁴x — действие Эйнштейна-Гильберта</p>
<p>S_topo = ∫ ρ_USA(r) · Φ_topo(r) √g d⁴x — топологический член</p>
<p>где Φ_topo(r) = 4πGA · ln(1 + r/r_c) — потенциал топологической компоненты.</p>
<p>[D] model S_agent = ∫ L_agent(X) √g d⁴x — действие состояния системы. S_agent требует явного вывода вариации δS_agent/δg^μν, статус [H].</p>
<p>[D] model L_agent = T[γ] − λ · C_risk · (1 − q) — натяжение минус диссипация. Модельный выбор: конкретный вид L_agent не выведен из топологии. Альтернативы: (a) L_agent = T[γ] − μ C_risk; (b) L_agent = H_Σ − D_diss; (c) L_agent = κ · ln(b₁).</p>
<h2 id="вариация-и-уравнение-поля">Вариация и уравнение поля</h2>
<p><strong>δS_USA/δg^μν = 0 даёт архитектурное построение уравнения поля.</strong></p>
<p><strong>Вывод Λ_cas g_μν из δS_topo пока не замкнут.</strong></p>
<p><strong>Для получения Λ_cas g_μν необходимо, чтобы часть действия имела структуру космологического члена:</strong></p>
<p><strong>S_Λ = −(Λ/8πG) ∫ √g d⁴x.</strong></p>
<p><strong>Статус: [H] для вывода Λ_cas g_μν из S_topo.</strong></p>
<p>где:</p>
<ul>
<li><p>G_μν = R_μν − ½ g_μν R — тензор Эйнштейна (из δS_g)</p></li>
<li><p>Θ_μν^topo = (2/√g) δS_topo/δg^μν — топологический тензор энергии-импульса</p></li>
<li><p>Θ_μν^agent = (2/√g) δS_agent/δg^μν — тензор состояния системы</p></li>
</ul>
<h2 id="численная-проверка-1">Численная проверка</h2>
<p>Метрика: Шварцшильд с USA-поправкой.</p>
<p>ds² = −(1 − 2GM/r + δUSA(r)) dt² + (1 − 2GM/r + δUSA(r))⁻¹ dr² + r² dΩ²</p>
<p>где δUSA(r) = 8πG ∫₀ʳ ρ_USA(s) s² ds / r — поправка от топологической плотности.</p>
<p>При r ≫ r_c: ведущий вклад δUSA стремится к константе.</p>
<p>Логарифмическая часть имеет дополнительный фактор ln r / r.</p>
<p>Заявленная асимптотика δUSA ~ ln r не следует из записанного интеграла.</p>
<p>Результат: поправка мала при r ≪ r_virial, значима при r ~ r_virial. Согласуется с плоской кривой вращения.</p>
<h2 id="ограничения-2">Ограничения</h2>
<ul>
<li><p>Явный вид S_topo требует более строгого вывода из топологии (не феноменология).</p></li>
<li><p>S_agent — модельный выбор [D] model.</p></li>
<li><p>Λ_cas как космологическая постоянная требует физического обоснования.</p></li>
<li><p>Не учитывает квантовые поправки.</p></li>
<li><p>Не проверен на точных решениях кроме Шварцшильда.</p></li>
</ul>

<h2 id="заключительное-заявление-3">Заключительное заявление</h2>
<h2 id="результат-δsδg-0-даёт-архитектурное-построение-уравнения-поля-s_agent-модельный-выбор">Результат: δS/δg = 0 даёт архитектурное построение уравнения поля; S_agent — модельный выбор</h2>

<h1 id="задача-15.-вывод-g-метакаскада-из-usa">Задача 15. Вывод G (метакаскада) из USA</h1>
<p><em>Что закрывает: Разрыв в определении метакаскада.</em></p>
<h2 id="три-механизма-g">Три механизма G</h2>
<p>[D] model G(O_t, S_t) обновляет оператор через три механизма:</p>
<ul>
<li><p>Механизм 1 — обновление весов: w_i → w_i + α(S_{t,i} − ⟨S_t⟩). Активные классы усиливаются, неактивные ослабляются.</p></li>
<li><p>Механизм 2 — обновление порога: κ → κ + β(I_actual − I_target). Порог когерентности адаптируется.</p></li>
<li><p>Механизм 3 — структурное расширение: H_latent → H_latent + γ ∇_S T[γ]. Новые классы возникают из латентного пространства.</p></li>
</ul>
<p>[D] model: α, β, γ — модельные параметры, не выведенные из USA.</p>
<h2 id="вывод-механизма-3-из-h¹m-σ-h">Вывод механизма 3 из H¹(M \ Σ) [H]</h2>
<p>[H] Механизм 3 можно вывести из топологии: новые классы в H¹(M \ Σ) возникают, когда траектория системы проходит через новую область M \ Σ, создавая новый гомотопический класс. Связь: γ ∇_S T[γ] ~ изменение b₁ при расширении M. Это требует формализации через гомологическую алгебру — открытый вопрос.</p>

<h1 id="задача-16.-вывод-ξq-из-первого-принципа">Задача 16. Вывод ξ(q) из первого принципа</h1>
<p><em>Что закрывает: Разрыв в фазовой модели.</em></p>
<h2 id="вывод-1">Вывод</h2>
<p><strong>[D] model (условная) Вывод ξ(q) = c(1−q)/q^β из USA:</strong></p>
<p>Шаг 1. Определение диссипации:</p>
<p>D_diss = Λ_cas − Λ_bal (разность каскадного роста и баланса)</p>
<p>В равновесии: Λ_bal = 0, D_diss = Λ_cas. В неравновесии: D_diss &gt; Λ_cas.</p>
<p>Шаг 2. Определение q:</p>
<p>q = κ/κ_max (из задачи 4) — доля актуализированной структуры</p>
<p>q = 1: полная актуализация, равновесие, D_diss = 0. q &lt; 1: частичная, D_diss &gt; 0.</p>
<p>Шаг 3. Функциональная форма [D] model:</p>
<p>D_diss = ξ(q) = c · (1−q)/q^β</p>
<p>Обоснование формы :</p>
<ul>
<li><p>(1−q) → 0 при q → 1: нет диссипации в равновесии ✓</p></li>
<li><p>(1−q) → 1 при q → 0: максимальная диссипация ✓</p></li>
<li><p>1/q^β: при q → 0 диссипация расходится (коллапс) ✓</p></li>
<li><p>Линейность по (1−q) — простейшая форма, согласованная с USA. Это модельный выбор [D] model.</p></li>
</ul>
<p>Шаг 4. Показатель β [H]:</p>
<p>β = codim(Σ) — коразмерность критического множества</p>
<p>Для generic dynamical systems: codim(Σ) = 1, β = 1. Это простейший случай.</p>
<p>β = n − d_H (коразмерность для фрактального множества).</p>
<p>Или: β_norm = 1 − d_H/n (нормированная коразмерность). Выбрать одно определение и не путать.</p>
<p>[D] model Для каких систем β = 1: (a) гладкие критические множества (гиперповерхности); (b) бифуркации коразмерности 1 (saddle-node, Hopf). Не работает для: (a) фрактальных Σ; (b) коразмерности &gt; 1.</p>
<p>Шаг 5. Константа c [H]:</p>
<p>c = γ_eff · σ · D_0 / K̃</p>
<p>[H] Вывод c из первых принципов: c зависит от γ_eff, σ (дисперсия возмущения), D_0 (характерный масштаб), K̃ (базовая когерентность). Это не свободный параметр, а комбинация параметров USA. Но значения σ и D_0 требуют определения для конкретной системы — открытый вопрос.</p>
<h2 id="численная-проверка-2">Численная проверка</h2>
<p>q = 0.999: ξ = 5.0050e-05, Λ_bal = -1.2525e-09 (вечность)</p>
<p>q = 0.92: ξ = 4.3478e-03, Λ_bal = -9.4245e-06 (старение)</p>
<p>q = 0.01: ξ = 4.9500e+00, Λ_bal = -3.1666e+00 (коллапс)</p>
<p>Асимптотика q → 1: Λ_bal ≈ −ξ²/2.</p>
<p>Это асимптотика, не фазовый переход. Для фазового перехода нужны: параметр порядка, предел, неаналитичность, две фазы.</p>
<h2 id="сравнение-с-альтернативными-формами-h">Сравнение с альтернативными формами [H]</h2>
<p>Открытый вопрос: какая форма ξ(q) лучше? Для ответа нужно:</p>
<ul>
<li><p>Сравнить с наблюдаемыми фазовыми переходами (старение, коллапс)</p></li>
<li><p>Проверить на Toy-моделях с известными фазами</p></li>
<li><p>Сравнить предсказания для q → 0 (коллапс) и q → 1 (вечность)</p></li>
</ul>
<h2 id="ограничения-4">Ограничения</h2>
<ul>
<li><p>Форма ξ(q) — модельный выбор [D] model, не вывод из первых принципов.</p></li>
<li><p>β = codim(Σ) — гипотеза [H] для конкретных систем.</p></li>
<li><p>c требует определения σ и D_0 для конкретной системы.</p></li>
<li><p>Линейность по (1−q) — простейшее предположение, не доказанное.</p></li>
</ul>
<h2 id="статус-d-model-для-формы-h-для-β-codimσ">Статус: [D] model для формы, [H] для β = codim(Σ)</h2>
<h2 id="заключительное-заявление-5">Заключительное заявление</h2>
<h2 id="результат-ξq-c1qqβ-выведена-как-модельный-выбор-β-codimσ-гипотеза">Результат: ξ(q) = c(1−q)/q^β выведена как модельный выбор; β = codim(Σ) — гипотеза</h2>
<h2 id="условия-линейность-по-1q-простейшее-предположение-c-требует-определения-σ-и-d_0">Условия: линейность по (1−q) — простейшее предположение; c требует определения σ и D_0</h2>
<h2 id="статус-d-model-для-формы-h-для-β-codimσ-1">Статус: [D] model для формы; [H] для β = codim(Σ)</h2>
<h2 id="граница-результата-результат-не-утверждает-фазовый-переход-2-го-рода-при-q-1-асимптотика-не-переход">Граница результата: результат НЕ утверждает фазовый переход 2-го рода при q → 1; асимптотика, не переход</h2>
<h2 id="продолжение-доказательство-β-codimσ-для-конкретных-систем-сравнение-с-наблюдаемыми-фазовыми-переходами">Продолжение: доказательство β = codim(Σ) для конкретных систем; сравнение с наблюдаемыми фазовыми переходами</h2>
<h1 id="задача-17.-истинная-невычислимость">Задача 17. Истинная невычислимость</h1>
<p><em>Что закрывает: Разрыв между вычислительной недоступностью и настоящей невычислимостью.</em></p>
<h2 id="условие-вынесено-в-основной-текст-d">Условие (вынесено в основной текст) [D]</h2>
<p>[D] КРИТИЧЕСКОЕ УСЛОВИЕ: сведение к halting problem работает только при неограниченном росте числа классов.</p>
<p>Для конечного пространства состояний: FIXED-POINT разрешима перебором.</p>
<p>Условия: 1. число состояний конечно; 2. пространство состояний конечно; 3. G эффективно вычислим; 4. переходы детерминированы/эффективно перечислимы.</p>
<p>Только тогда O(2^N) может появиться как грубая верхняя оценка для конкретного конечного представления.</p>
<p>Условие выполняется, если метакаскад включает механизм 3 (структурное расширение), который позволяет числу классов расти неограниченно (как лента машины Тьюринга).</p>
<h2 id="сведение">Сведение</h2>
<p><strong>G Turing-complete + неограниченное состояние ⇒ FIXED-POINT может быть неразрешимой. Статус: [T] cond.</strong></p>
<p>Доказательство (сведение к проблеме остановки):</p>
<p>1. Конструкция: кодируем машину Тьюринга M как состояние USA X_M:</p>
<ul>
<li><p>Лента M → компоненты состояния X_M</p></li>
<li><p>Переходы δ_M → оператор G_M</p></li>
<li><p>Начальная конфигурация (M, x) → O₀^M</p></li>
</ul>
<p>2. Соответствие:</p>
<ul>
<li><p>Один шаг метакаскада O_{t+1} = G_M(O_t, S_t) = один шаг M</p></li>
<li><p>M останавливается ⟺ метакаскад достигает неподвижной точки</p></li>
<li><p>M не останавливается ⟺ метакаскад продолжается бесконечно</p></li>
</ul>
<p>3. Редукция:</p>
<p>HALT(M, x) ≤_m FIXED-POINT(G_M, O₀^M)</p>
<p>Если FIXED-POINT разрешима, то HALT разрешима. HALT неразрешима (Тьюринг, 1936). Следовательно FIXED-POINT неразрешима.</p>
<h2 id="формализация-класса-g-d">Формализация класса G [D]</h2>
<p>Какой класс G достаточен для кодирования любой машины Тьюринга?</p>
<p>Достаточно, если G включает:</p>
<ul>
<li><p>Механизм 3 (структурное расширение) — для роста ленты</p></li>
<li><p>Обновление весов (механизм 1) — для записи на ленту</p></li>
<li><p>Условный переход (через порог κ) — для переходов δ_M</p></li>
</ul>
<p>Формально: G ∈ class TURING-COMPLETE если G может симулировать любую машину Тьюринга. Это требует неограниченной памяти (механизм 3) и условных переходов (порог κ).</p>
<h2 id="сравнение-с-другими-неразрешимыми-задачами-h">Сравнение с другими неразрешимыми задачами [H]</h2>
<ul>
<li><p>Post Correspondence Problem: можно свести к FIXED-POINT через кодирование пар строк как классов гомологий.</p></li>
<li><p>Wang Tiles: замощение плоскости сводится к неограниченному росту классов.</p></li>
<li><p>Сведение к halting problem — наиболее прямое и естественное.</p></li>
</ul>
<h2 id="численная-проверка-d">Численная проверка [D]</h2>
<p>Модельная система: машина Тьюринга с известным поведением.</p>
<p>Пример: M = «увеличить x на 1, остановиться при x = 5». Метакаскад: 5 шагов, неподвижная точка достигается.</p>
<p>Пример: M = «увеличить x на 1 бесконечно». Метакаскад: бесконечное число шагов, неподвижная точка не достигается.</p>
<p>Результат: метакаскад воспроизводит поведение M ✓</p>
<h2 id="ограничения-5">Ограничения</h2>
<ul>
<li><p>Только при неограниченном росте классов (механизм 3).</p></li>
<li><p>Для конечного числа классов FIXED-POINT разрешима перебором.</p></li>
<li><p>Сведение корректно при G ∈ TURING-COMPLETE.</p></li>
</ul>
<h2 id="статус-t-cond-условно-доказано-до-полной-формализации-reduction-требуется-спецификация-пространства-операторов-кодирования-конфигураций-и-вычислимости-g">Статус: [T] cond — условно доказано до полной формализации reduction; требуется спецификация пространства операторов, кодирования конфигураций и вычислимости G</h2>
<h2 id="заключительное-заявление-6">Заключительное заявление</h2>
<h2 id="результат-fixed-point-может-быть-неразрешимой-при-g-turing-complete-и-неограниченном-состоянии">Результат: FIXED-POINT может быть неразрешимой при G Turing-complete и неограниченном состоянии</h2>
<h2 id="условия-неограниченный-рост-классов-механизм-3-g-turing-complete-для-конечного-состояния-разрешима-перебором">Условия: неограниченный рост классов (механизм 3); G ∈ TURING-COMPLETE; для конечного состояния разрешима перебором</h2>
