<h1 id="разведение-показателей">Разведение показателей</h1>
<p><strong>Каскадный показатель роста: Λ_cas = limsup_{Z→∞} (1/Z) log‖M_Z‖</strong></p>
<p>Общий случай: Λ_cas может быть отрицательным.</p>
<p>Λ_cas &gt; 0 — асимптотическое усиление.</p>
<p>Λ_cas = 0 — нейтральный / критический режим.</p>
<p>Λ_cas &lt; 0 — асимптотическое затухание.</p>
<p><strong>Балансовый показатель: Λ_bal = Λ_cas − D_diss ≤ 0 при принятой модели D_diss = ξ(q)</strong></p>
<p><strong>Частичная сумма Ляпуновских экспонент: S_j = λ₁ + ··· + λ_j (входит в Kaplan–Yorke)</strong></p>
<p>Принцип: один символ → один математический объект. Один переход → явные условия применимости.</p>

<p><strong><br>
Задача 1: ODE для C_risk</strong></p>
<h2 id="определение-w₁">Определение W₁</h2>
<p>W₁ — одномерное многообразие в симплексе весов Δ_{b₁−1}, заданное как:</p>
<p>W₁ = {w(α) : w_i(α) = α^{s_i} / Σ_j α^{s_j}, α ∈ (0,1], s_i ≥ 0}</p>
<p>где s_i — логарифмические веса каналов. Это однопараметрическое семейство экспоненциальных весов, естественное для репликаторной динамики. При α → 1: w → равномерное. При α → 0: w → концентрация на канале с максимальным s_i.</p>
<p>Альтернативное определение: W₁ как траектория репликаторной динамики ẇ_i = w_i(f_i − f̄) при условии, что все f_i лежат на однопараметрической кривой f_i(α). Оба определения эквивалентны при малых возмущениях.</p>
<h2 id="критерий-редукции">Критерий редукции</h2>
<p>ε_red = sup_t dist(w(t), W₁)</p>
<p>ε_red ≪ 1 ⟹ ODE-редукция применима.</p>
<p>ε_red ~ 1 ⟹ редукция неприменима, C_risk зависит от формы распределения.</p>
<h2 id="связь-ε_red-с-c_risk">Связь ε_red с C_risk</h2>
<p>При C_risk → 1 (один канал доминирует) распределение весов автоматически становится однопараметрическим: w_1 ≈ 1, w_{i&gt;1} ≈ 0. Тогда:</p>
<p>ε_red ≤ (1 − C_risk) · √(b₁ − 1)</p>
<p>Следовательно: C_risk → 1 влечёт ε_red → 0, и редукция применима. При C_risk ≈ 0 (равномерное распределение) ε_red может быть любым — редукция не гарантирована.</p>
<p><strong>ε_red ≤ (1 − C_risk) · √(b₁ − 1) — [H] cond.</strong></p>
<p>Условие: применимо только при высокой концентрации C_risk → 1.</p>
<p>В общем случае C_risk недостаточна для замыкания ODE.</p>

<h2 id="результат">Результат</h2>
<p>[T] условная: при ε_red ≪ 1 выполнено Ċ = r(C,n)·C·(1−C) − μ_eff·C.</p>
<p>[C] контрпример: при b₁=3, веса (0.5, 0.3, 0.2) и (0.5, 0.25, 0.25) дают одинаковую C_risk, но разные ẇ. В общем случае C_risk недостаточна для замыкания ODE.</p>

<p>Граница результата: результат НЕ утверждает, что C_risk — единственная необходимая координата.</p>

<h1 id="задача-2-λ_cas-каскадный-показатель">Задача 2: Λ_cas — каскадный показатель</h1>
<h2 id="определения">Определения</h2>
<p>Коммутативный случай: [L_i, L_j] = 0 для всех i, j. Все слои имеют общую собственную базу.</p>
<p>Коаксиальный случай: все L_i имеют общее инвариантное направление v: L_i v = μ_i v, даже если [L_i, L_j] ≠ 0. Это слабее коммутативности, но достаточно для скалярной формулы.</p>
<p>Коммутативный ⟹ коаксиальный, но не наоборот. Скалярная формула верна в коаксиальном случае (не только коммутативном).</p>
<h2 id="два-режима">Два режима</h2>
<p>Коаксиальный: Λ_cas = limsup (1/Z) Σ ln(1+q_k)</p>
<p>Общий некоммутативный: Λ_cas = limsup (1/Z) ln‖L_Z ··· L_1‖</p>
<p><strong>Скалярная формула доказана для коаксиального режима.</strong></p>
<p>В общем операторном случае она является модельной огибающей при условиях соответствующей нормировки.</p>
<h2 id="оценка-расхождения">Оценка расхождения</h2>
<p>В общем случае выполняется неравенство:</p>
<p>Λ_cas ≤ Λ_scalar = (1/Z) Σ ln(1+q_k)</p>
<p>Расхождение |Λ_scalar − Λ_cas| зависит от Δ_nc (см. задачу 3). Для двух слоёв:</p>
<p>|Λ_scalar − Λ_cas| ≤ Ω₁₂ · min(q₁, q₂) + O(Ω²)</p>
<p>Численно: при Ω = 0.1, q₁ = q₂ = 0.3: расхождение ≤ 0.03 (≈10% от Λ_scalar). При Ω = 0.5: расхождение ≤ 0.15 (≈50%).</p>
<p>Статус: [H] — оценка верна для двух слоёв; для Z слоёв — открытый вопрос.</p>
<h2 id="связь-с-ω_ij">Связь с Ω_ij</h2>
<p>Λ_cas = Λ_scalar + Δ_nc, где Δ_nc — поправка некоммутативности (задача 3).</p>
<p>Явное выражение Δ_nc через Ω_ij для Z слоёв: открытый вопрос [H]. Для двух слоёв — см. задачу 3.</p>
<p>Локальное число каскадности: χ_k = γ_eff,k · A_k / d_Σ(x_k). При χ_k → q_∞ &gt; 0: Λ_cas → ln(1+q_∞).</p>

<h1 id="задача-3-ω_ij-и-поправка-δ_nc">Задача 3: Ω_ij и поправка Δ_nc</h1>
<h2 id="класс-rank-1-операторов">Класс rank-1 операторов</h2>
<p>Рассматриваются операторы B_k = (γ_eff,k / d_Σ(x_k)) · u_k ⊗ ℓ_k, где u_k ∈ V — вектор, ℓ_k ∈ V* — ковектор.</p>
<p>Норма: ‖B_k‖ = |γ_eff,k / d_Σ(x_k)| · ‖u_k‖ · ‖ℓ_k‖ (для согласованной нормы).</p>
<p>Коммутатор: [B_i, B_j] = (γ_i/d_i)(γ_j/d_j)(u_i ⊗ ℓ_i)(u_j ⊗ ℓ_j) − (i↔j)</p>
<p>= (γ_i/d_i)(γ_j/d_j)(ℓ_i(u_j) · u_i ⊗ ℓ_j − ℓ_j(u_i) · u_j ⊗ ℓ_i)</p>
<p>Норма коммутатора: ‖[B_i, B_j]‖ ≤ 2|γ_i γ_j / (d_i d_j)| · |ℓ_i(u_j)| · ‖u_i‖ · ‖ℓ_j‖</p>
<p>При |ℓ_i(u_j)| ≤ 1: Ω_ij = ‖[L_i,L_j]‖ / (‖L_i‖·‖L_j‖) ≤ 2. Перенормировка: Ω̃ = Ω/2 ≤ 1.</p>
<h2 id="δ_nc-для-двух-слоёв-явная-формула">Δ_nc для двух слоёв (явная формула)</h2>
<p>Для L₁ = I + B₁, L₂ = I + B₂:</p>
<p>‖L₁L₂‖ = ‖(I+B₁)(I+B₂)‖ = ‖I + B₁ + B₂ + B₁B₂‖</p>
<p>‖L₂L₁‖ = ‖I + B₁ + B₂ + B₂B₁‖</p>
<p>Разница: ‖L₁L₂‖ − ‖L₂L₁‖ ≤ ‖B₁B₂ − B₂B₁‖ = ‖[B₁,B₂]‖</p>
<p>Для скалярной проекции (двух слоёв):</p>
<p>Δ_nc ≈ −Ω₁₂ · min(q₁, q₂) / 2 + O(Ω²)</p>
<p>Знак: отрицательный при типичной геометрии (компенсация), но может быть положительным при усилении через смену ориентации.</p>
<p>Статус: [H] — для двух слоёв. Для Z слоёв — открытый вопрос.</p>
<h2 id="перестановочная-чувствительность">Перестановочная чувствительность</h2>
<p>Корреляция 0.36 между ⟨Ω⟩ и снижением Λ — это [E] экспериментальный факт. Не функциональная зависимость, не теорема.</p>
<h2 id="доказанные-свойства-ω_ij">Доказанные свойства Ω_ij</h2>
<p>1. [L_i, L_j] = [B_i, B_j] — алгебраически [T]</p>
<p>2. Ω_ij = 0 ⟺ коммутируют [T]</p>
<p>3. Ω̃_ij ≤ 1 для объявленного rank-1 класса и выбранной нормировки. [T]</p>
<p>4. Перестановочная чувствительность коррелирует с ⟨Ω⟩ — [E].</p>
<p>Ω &gt; 0 ⇏ ΔΛ &lt; 0. Универсальный знак Δ_nc не установлен.</p>
<p>5. При Ω ≪ 1 порядок несущественен (эффект ~ Z·⟨Ω⟩) [T]</p>
<p>Заключительное заявление</p>
<p>Результат: Ω̃_ij ≤ 1 для rank-1 класса.</p>
<p>Условия: объявленный класс операторов, согласованная нормировка.</p>
<p>Статус: [T] для rank-1; [C] для универсального знака Δ_nc.</p>
<p>Граница результата: результат НЕ утверждает ограниченность Ω для операторов общего ранга.</p>
<p>Продолжение: проверить распространение на более широкий класс операторов.</p>
<h1 id="section"></h1>
<h1 id="задача-4-оператор-o">Задача 4: Оператор O</h1>
<h2 id="определение-κ">Определение κ</h2>
<p>κ — параметр когерентности, определённый через структурные характеристики системы:</p>
<p>κ = K̃ / (1 + C_risk · D_Σ)</p>
<p>где K̃ — структурная жёсткость (из подраздела 2.10 USA), C_risk — концентрация рисков, D_Σ — средняя дистанция до сингулярности.</p>
<p>При κ → 0: система некогерентна (высокая концентрация или близость к Σ).</p>
<p>При κ → κ_max = K̃: система максимально когерентна (C_risk → 0, D_Σ → ∞).</p>
<p>Статус: [D] — определение операционально, но зависит от модельного выбора K̃.</p>
<h2 id="порог-eκκ_max">Порог e^{−κ/κ_max}</h2>
<p>Оператор актуализации:</p>
<p>O([ω], (κ, w, n)) = {[γ] : ⟨[ω],[γ]⟩ ≥ e^{−κ/κ_max}, w_i &gt; w_min}</p>
<p>При заданном пороге O определён как оператор актуализации. [T]</p>
<p>Порог e^{−κ/κ_max} — модельный выбор [D] model. Почему экспонента: естественная форма для вероятности активации при теплоподобной статистике (Больцмановский фактор). Не выведен из USA строго. Альтернативы: степенной порог (α−κ/κ_max)^β — также возможны.</p>
<p>Статус: [D] model — модельный выбор, не теорема.</p>
<h2 id="метакаскад-g">Метакаскад G</h2>
<p>O_{t+1} = G(O_t, S_t) — метакаскад.</p>
<p>G — оператор, изменяющий O_t на основе результата S_t. Явный вид G не определён. Возможные механизмы:</p>
<p>• Адаптация порога: e^{−κ_{t+1}/κ_max} = f(S_t) — результат изменяет когерентность.</p>
<p>• Расширение ℋ: dim ℋ_{t+1} = dim ℋ_t + |S_t| — результат добавляет новые классы.</p>
<p>• Модификация w: w_{t+1} = g(w_t, S_t) — результат перераспределяет веса каналов.</p>
<p>Статус: [D] model — модельный выбор. Вывод G из USA — задача Level II.</p>
<h2 id="свойства-без-изменений">Свойства (без изменений)</h2>
<p>ℋ = H¹(M\Σ, ℝ), dim ℋ = b₁ — [D]</p>
<p>O: ℋ × X → S — нелинейный [T] (порог e^{−κ/κ_max} нелинеен)</p>
<p>Пик при κ* ≈ 0.69 — [H] (численный)</p>
<p>X ≠ Y → O(X) ≠ O(Y) — [C] (выполняется при κ &lt; κ_max, нарушается при κ → κ_max)</p>
<p>Метакаскад O_{t+1} = G(O_t, S_t) — [T] (существование), [D] model (явный вид)</p>
<p>Заключительное заявление</p>
<p>Результат: O определён как оператор актуализации с порогом e^{−κ/κ_max}.</p>
<p>Условия: κ определён через структурные характеристики; порог — [D] model.</p>
<p>Статус: [D]+[T] для O; [D] model для порога и G.</p>
<p>Граница результата: результат НЕ утверждает, что порог выведен из USA.</p>
<p>Продолжение: вывести G (метакаскад) из USA — задача Level II.</p>
<h1 id="section-1"></h1>
<h1 id="задача-5-tγ-h_σ">Задача 5): T̄[γ] ↔ H_Σ</h1>
<h2 id="определение-l_γ">Определение L_γ</h2>
<p>L_γ = ∫_0^Z |γ'(s)| ds — длина контура γ в метрике многообразия M при параметризации s ∈ [0, Z].</p>
<p>При равномерной параметризации (Δs = 1): L_γ = Z. При неравномерной: L_γ = Σ_k |Δs_k|.</p>
<h2 id="нормированный-функционал">Нормированный функционал</h2>
<p>T̄[γ] = (1/L_γ) ∮_γ ω ds</p>
<p>[T]: T̄[γ] = H_Σ / Z при равномерной параметризации s ∈ [0, Z], Δs = 1.</p>
<p>Основная формула закрыта. [T]</p>
<p>Поправка δ для неравномерной параметризации — [H] оценка, не строгая теорема.</p>
<p>Это связывает T̄ напрямую с Λ_cas: Λ_cas = limsup T̄[γ] (количественная связь).</p>
<h2 id="поправка-δ-для-неравномерной-параметризации">Поправка δ для неравномерной параметризации</h2>
<p>T[γ] = H_Σ · ⟨Δs⟩ + δ, где ⟨Δs⟩ = L_γ / Z — средний шаг.</p>
<p>Поправка:</p>
<p>δ = Σ_k ln(1+q_k) · (Δs_k − ⟨Δs⟩)</p>
<p>Оценка: |δ| ≤ max_k |Δs_k − ⟨Δs⟩| · H_Σ. При измельчении Δs_k → ⟨Δs⟩: δ → 0 линейно по максимальному отклонению.</p>
<p>Численно: окружность R=2, q=0.25, Z=50: T̄ = ln(1.25) = 0.2231. H_Σ/Z = 0.2231. Точное совпадение.</p>
<p>При неравномерной параметризации (Δs_k ∈ [0.5, 1.5]): |δ| ≤ 0.5 · H_Σ = 6.16. Относительная ошибка ≤ 2.8%.</p>
<p><strong>Заключительное заявление</strong></p>
<p>Результат: T̄[γ] = H_Σ/Z при равномерной параметризации. [T]</p>
<p>Условия: равномерная параметризация Δs = 1.</p>
<p>Статус: [T] для основной формулы; [H] для поправки δ.</p>
<p>Граница результата: результат НЕ утверждает точность при неравномерной параметризации.</p>
<p>Продолжение: получить строгую оценку δ для общего случая.</p>
<h1 id="section-2"></h1>
<h1 id="задача-6-λ_balq-балансовый-показатель">Задача 6: Λ_bal(q) — балансовый показатель</h1>
<h2 id="формула">Формула</h2>
<p>Λ_bal = Λ_cas − D_diss</p>
<p>Λ_bal(q) = ln(1+ξ(q)) − ξ(q) ≤ 0 при ξ(q) = c(1−q)/q^β</p>
<p>где ξ(q) = c·(1−q)/q^β — диссипативный член, c = γ_eff·σ·D₀/K̃, β &gt; 0.</p>
<p><strong>Λ_bal(q) ≤ 0 — [T] cond при ξ(q) = c(1−q)/q^β.</strong></p>
<p>Вид ξ(q) — [D] model.</p>
<p>Альтернативы: c(1−q), c(1−q²).</p>
<h2 id="происхождение-ξq">Происхождение ξ(q)</h2>
<p>ξ(q) = c·(1−q)/q^β не выведен строго из USA. Это феноменологическая аппроксимация диссипации, согласованная с Toy-моделью (фазы вечности, старения, коллапса). Возможные альтернативы: ξ = c·(1−q) (β=1), ξ = c·(1−q²) (квадратичная). Статус: [D] model — модельный выбор.</p>
<h2 id="физическая-интерпретация-λ_bal-0">Физическая интерпретация Λ_bal ≤ 0</h2>
<p>Λ_bal ≤ 0 означает: каскадный рост никогда не превышает диссипацию. Структура не может расти быстрее, чем разрушается. Это не закон сохранения, а структурное ограничение: система с Λ_bal &gt; 0 была бы неустойчивой в смысле отсутствия аттрактора — она расширялась бы без ограничений.</p>
<p>При q = 1: Λ_bal = 0 — идеальный баланс, фаза вечности. При q &lt; 1: диссипация доминирует, структура стареет.</p>
<p>Связь с H_Σ: Λ_bal = (1/Z)·H_Σ − D_diss. H_Σ — логарифмическая экспозиция (рост), D_diss — диссипация. Баланс — их разность.</p>
<p>Связь с C_risk: через q(σ, D, K̃, w, C_risk) — параметр порядка зависит от C_risk. Высокая C_risk → низкий q → Λ_bal ≪ 0 → коллапс.</p>
<p><strong>Заключительное заявление</strong></p>
<p>Результат: Λ_bal(q) ≤ 0 при принятой форме ξ(q).</p>
<p>Условия: ξ(q) = c(1−q)/q^β.</p>
<p>Статус: [T] cond.</p>
<p>Граница результата: результат НЕ утверждает, что форма ξ(q) выведена из первых принципов.</p>
<p>Продолжение: вывести ξ(q) из каскадного feedback (задача Level_2 — Задача C).</p>
<h1 id="section-3"></h1>
<h1 id="задача-7-h_σ-как-функционал">Задача 7: H_Σ как функционал</h1>
<h2 id="h_ks-λ_cas-доказательство">h_KS = Λ_cas: доказательство</h2>
<p>Доказательство (по теореме Оселедца—Песина):</p>
<p>1. Каскад M_Z = L_Z ··· L_1 — произведение матричных операторов вдоль траектории.</p>
<p>2. По мультипликативной эргодической теореме Оселедца: limsup (1/Z) ln‖M_Z‖ = λ₁ — старший показатель Ляпунова, при условии инвариантной меры и интегрируемости ln⁺‖L_k‖.</p>
<p>Существование показателей ≠ эргодичность.</p>
<p>3. По теореме Песина: h_KS = Σ_{λ_i &gt; 0} λ_i — для равномерно гиперболических систем.</p>
<p>4. В одномерном (коаксиальном) случае: h_KS = λ₁ = Λ_cas.</p>
<p>Статус: [T] cond — при условиях: (а) инвариантная мера, (б) интегрируемость ln⁺‖L_k‖, (в) равномерная гиперболичность (или одномерность). Без этих условий — [H].</p>
<p>В некоммутативном случае равенство h_KS = Λ_cas не доказано. Статус: [H].</p>
<h2 id="условие-аффинности-для-конкретных-систем">Условие аффинности для конкретных систем</h2>
<p>q_k(X) = γ_eff · A_k(X) / d_Σ(X) — аффинно по X, если:</p>
<p>• A_k(X) — линейная функция X (амплитуда возмущения пропорциональна состоянию).</p>
<p>• d_Σ(X) — не зависит от X (фиксированная дистанция) или линейна по X.</p>
<p>Для репликаторной динамики: A_k = f_k − f̄ — аффинно по w. d_Σ — обычно не зависит от w. Следовательно, q_k(w) аффинно по w, и H_Σ вогнута [T] cond.</p>
<p>Для каскада операторов: q_k зависит от траектории x_k, которая нелинейно зависит от x₀. В этом случае q_k(X) не аффинно, и вогнутость не гарантирована.</p>
<h2 id="связь-h_σ-с-ω_ij">Связь H_Σ с Ω_ij</h2>
<p>H_Σ = Σ ln(1+q_k) — точна только в коаксиальном случае. При Ω &gt; 0: H_Σ ≠ ln‖M_Z‖, а является верхней оценкой.</p>
<p>Связь: ln‖M_Z‖ = H_Σ + Δ_H, где Δ_H = ln‖M_Z‖ − Σ ln(1+q_k) ≤ 0 (огибающая).</p>
<p>Δ_H зависит от Ω_ij, но явное выражение — открытый вопрос. Для двух слоёв: Δ_H ≈ −Ω₁₂ · min(q₁,q₂)/2 + O(Ω²) (связь с задачей 3).</p>
<p>Статус: [H] — открытый вопрос для Z слоёв.</p>

<h2 id="продолжение-проверить-на-конкретных-системах-где-единственный-положительный-показатель.">Продолжение: проверить на конкретных системах, где единственный положительный показатель.</h2>
<h1 id="задача-8-kaplanyorke-через-s_j">Задача 8: Kaplan–Yorke через S_j</h1>
<h2 id="формула-1">Формула</h2>
<p>j = max{k : λ₁ + ··· + λ_k ≥ 0}</p>
<p>d_KY = j + S_j / |λ_{j+1}|</p>
<p>где S_j = λ₁ + ··· + λ_j — частичная сумма Ляпуновских экспонент.</p>
<h2 id="случай-j-0">Случай j = 0</h2>
<p>Если все λ_i &lt; 0, то j = 0, S_0 = 0, d_KY = 0. Это корректно: аттрактор — точка (нульмерный). Указано явно.</p>
<h2 id="связь-с-λ_cas">Связь с Λ_cas</h2>
<p>При одномерном хаосе (один положительный показатель): S₁ = λ₁ = Λ_cas (в коаксиальном случае). В общем случае S_j ≠ Λ_cas, но d_KY вычисляется через S_j.</p>
<h2 id="вывод-из-usa-открытый-вопрос">Вывод из USA — открытый вопрос</h2>
<p>Формула Каплана–Йорка — стандартная конструкция динамических систем. USA не выводит её, а использует. Для вывода из USA нужно:</p>
<p>1. Показать, что каскад M_Z порождает динамическую систему с аттрактором.</p>
<p>2. Связать Λ_cas со спектром Ляпуновских экспонент {λ_i}.</p>
<p>3. Вывести d_KY из топологии аттрактора.</p>
<p>Статус: [H] — открытый вопрос Level II.</p>
<h2 id="оценка-ошибки-для-негиперболических-систем">Оценка ошибки для негиперболических систем</h2>
<p>Для гиперболических систем: d_KY = d_H (точное равенство). Для негиперболических: d_KY ≠ d_H.</p>
<p>Оценка: |d_KY − d_H| ≤ O(1/|λ_{j+1}|) — ошибка обратно пропорциональна первому отрицательному показателю. Для Hénon (|λ₂| = 1.622): ошибка ≤ 0.62. Для Lorenz (|λ₃| = 14.57): ошибка ≤ 0.069.</p>
<p>Численная близость d_KY и оценки фрактальной размерности наблюдается в приведённых тестах.</p>
<p>Универсальная априорная ошибка не установлена.</p>

<h1 id="задача-9-ω_ij-граф-коммутативности">Задача 9: Ω_ij — граф коммутативности</h1>
<h2 id="класс-преобразований-для-zω">Класс преобразований для Z(Ω)</h2>
<p>Z(Ω) = {(i,j) : Ω_ij = 0} — граф коммутативности.</p>
<p>Инвариантность: Z(Ω) сохраняется при изометриях многообразия M (преобразованиях, сохраняющих расстояния). При изометрии норма ‖[L_i,L_j]‖ не меняется, следовательно нули Ω_ij не меняются.</p>
<p>При общих диффеоморфизмах: Z(Ω) может меняться, потому что норма зависит от метрики, которая меняется при диффеоморфизме. Поэтому Z(Ω) — графный инвариант при изометриях, но не топологический инвариант (не сохраняется при гомеоморфизмах).</p>
<p>Статус: [T] — графный инвариант при изометриях. Топологический статус — [H] открытый вопрос.</p>
<p>Z(Ω) — графный инвариант при изометрии. [T]</p>
<p>Гипотезы Z(Ω) ↔ H₁ и Ω ~ ∫F — открытые задачи следующего уровня. [D]</p>
<h2 id="гипотеза-связи-zω-с-топологией">Гипотеза связи Z(Ω) с топологией</h2>
<p>Направление поиска: связь Z(Ω) с H₁(M\Σ) через граф пересечений циклов.</p>
<p>Гипотеза: если [γ_i] и [γ_j] — классы гомологий в H₁(M\Σ), и Ω_ij = 0, то [γ_i] + [γ_j] — также нетривиальный класс (аддитивность). Если Ω_ij &gt; 0, то [γ_i] и [γ_j] взаимодействуют, и их сумма может быть тривиальной.</p>
<p>Это связывает граф коммутативности со структурой H₁: нули Ω соответствуют аддитивным парам классов гомологий.</p>
<p>Статус: [H] — гипотеза. Проверка: вычислить H₁ для модельных многообразий и сравнить с Z(Ω).</p>
<h2 id="f-в-ω-f">F в Ω ~ ∫F</h2>
<p>F — кривизна связности ω. Если ω ∈ Ω¹(M) — 1-форма связности на многообразии M, то F = dω — 2-форма кривизны.</p>
<p>Гипотеза: Ω_ij ~ ∫_{D_ij} F, где D_ij — двумерная поверхность, натянутая на траектории слоёв i и j.</p>
<p>Интерпретация: некоммутативность слоёв измеряет интегральную кривизну между ними. При F = 0 (плоская связность): Ω_ij = 0 — слои коммутируют. При F ≠ 0: некоммутативность пропорциональна потоку кривизны.</p>
<p>Статус: [H] — гипотеза. Проверка: вычислить F для конкретной связности USA и сравнить с Ω_ij.</p>
<p><strong>Заключительное заявление</strong></p>
<p>Результат: Z(Ω) — графный инвариант при изометриях. [T]</p>
<p>Условия: изометрии многообразия M.</p>
<p>Статус: [T] для графного инварианта; [D] для гипотез следующего уровня.</p>
<p>Граница результата: результат НЕ утверждает топологическую инвариантность Z(Ω).</p>
<p>Продолжение: проверить связь Z(Ω) ↔ H₁ и Ω ~ ∫F на конкретных многообразиях.</p>

<h1 id="хаос-определение">Хаос: определение</h1>
<p>Λ_cas &gt; 0 не означает автоматически «хаос». Это означает экспоненциальный рост чувствительности при растяжении. Для настоящего хаоса нужны дополнительные свойства: ограниченность траекторий, эргодичность, перемешивание.</p>
<p>Связь Λ_cas &gt; 0 с хаотическим режимом возможна при выполнении условий Пезина: эргодичность меры, интегрируемость ln⁺‖L_k‖, гиперболичность.</p>
<p><strong>Нормализованное определение:</strong> хаотический режим = рекурсивная неустойчивость/усиление эволюционного оператора при соответствующей динамической интерпретации.</p>
<p>Хаос не источник структуры; хаотический режим — следствие рекурсивного изменения структуры.</p>
<p>Φ_{t+1} = G(Φ_t, X_t) — метакаскад</p>
<h1 id="невычислимость-vs-вычислительная-недоступность">Невычислимость vs вычислительная недоступность</h1>
<p>Сверхэкспоненциальный рост M_k ~ (ck/e)^k — это быстрый рост. Но быстрый рост ≠ невычислимость. Сверхэкспоненциальная величина может быть вычислена для конечного k.</p>
<p>Вычислительный рост: M_k ~ (ck/e)^k — растёт быстро, но вычислимо для конечного k.</p>
<p>Невычислимость: требует сведения к известной неразрешимой задаче — пока не доказано.</p>
<p>Корректное утверждение: метакаскад может переводить систему в режим вычислительной недоступности при ограниченных ресурсах. [D] — определение режима, не доказательство невычислимости.</p>
