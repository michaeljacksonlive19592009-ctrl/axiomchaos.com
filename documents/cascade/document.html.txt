<p>Версия: v1.0 | Дата: 30/09/2026 | Статус: рабочий документ, открытый для роста</p>
<h2 id="преамбула">Преамбула</h2>
<p>Этот документ фиксирует каскадный слой USA::Box как самостоятельный объект исследования. Он вырастает из математического ядра (Universal Map, секции 9–10) и результатов задач A–F (Level II–III), но не повторяет их — он расширяет каскад в прикладные области, начиная с энергетики.</p>
<p>Принцип именования: название процесса отделено от математических величин. USA-каскад — это имя режима, а не одной переменной. Это позволяет использовать термин в инженерных и научных контекстах без смешения с конкретными формулами.</p>
<h2 id="часть-i.-имя-и-объект">Часть I. Имя и объект</h2>
<h3 id="usa-каскад-определение">1.1. USA-каскад — определение</h3>
<p>USA-каскад — последовательность преобразований, при которой состояние, результат одного этапа или изменение оператора становится входом следующего этапа, потенциально изменяя последующую динамику.</p>
<p><strong>Формально:</strong></p>
<p>X_{k+1} = Φ_k(X_k, ε_k)</p>
<p><strong>А если меняется и сам оператор:</strong></p>
<p>Φ_{k+1} = G(Φ_k, X_k)</p>
<p>Тогда:</p>
<p><strong>X_0 → X_1 → X_2 → ⋯ → X_Z</strong></p>
<p>— каскад.</p>
<p><strong>Φ_0 → Φ_1 → Φ_2 → ⋯</strong></p>
<p>— метакаскад.</p>

<h2 id="часть-ii.-математическое-ядро">Часть II. Математическое ядро</h2>
<h3 id="операторный-каскад">2.1. Операторный каскад</h3>
<p>Для последовательности локальных операторов L_k:</p>
<p>M_Z = L_Z · L_{Z-1} · ⋯ · L_1</p>
<p>Кандидат на локальную форму вблизи множества Σ:</p>
<p>L_k = I + [γ_k / d(x_k, Σ)] · P_k</p>
<p>где P_k — проектор, γ_k — интенсивность, d(x_k, Σ) — расстояние до сингулярного множества. Регуляризация: d_{Σ,ε} = √(d_Σ² + ε²).</p>
<h3 id="скалярная-проекция">2.2. Скалярная проекция</h3>
<p>При коаксиальной или коммутативной структуре операторный каскад проектируется в скалярный:</p>
<p>M_Z ≈ ∏_{k=1}^{Z} (1 + q_k), q_k = γ_k · A_k / D_k</p>
<p>где q_k — отношение воздействия к устойчивому запасу на шаге k.</p>
<p><strong>USA cascade factor:</strong></p>
<p><strong>M_USA = ∏_{k=1}^{Z} (1 + q_k)</strong></p>
<p><strong>USA cascade log:</strong></p>
<p><strong>H_USA = ln M_USA = Σ_k ln(1 + q_k)</strong></p>
<p><strong>USA cascade exponent:</strong></p>
<p><strong>Λ_cas = limsup_{Z→∞} (1/Z) ln ||M_Z||</strong></p>

<h2 id="часть-iii.-применение-к-энергетике">Часть III. Применение к энергетике</h2>
<p>В современной энергетике уже используются каскадное управление, иерархические уровни управления и рекурсивные расчёты потоков. USA-каскад не заменяет существующие методы, а даёт им дополнительный слой описания — универсальный язык измерения каскадности.</p>
<h3 id="уровень-i-каскад-преобразования-энергии">3.1. Уровень I — Каскад преобразования энергии</h3>
<p>Простейший случай:</p>
<p>E_0 → E_1 → E_2 → E_3</p>
<p>Например: топливо → тепло → механическая энергия → электричество → полезная нагрузка.</p>
<p>Обычная энергетика:</p>
<p>E_out = E_in · ∏_k η_k</p>
<p><strong>USA добавляет:</strong></p>
<p><strong>E_{k+1} = Φ_k(E_k, X_k)</strong></p>
<p>где состояние системы включает не только энергию:</p>
<p>X_k = (E_k, T_k, p_k, w_k, Σ_k, R_k, ...)</p>
<p>Следующий этап зависит от истории и состояния предыдущего. Это динамический энергетический каскад, гораздо ближе к реальности сложных энергетических систем, где электрические, газовые, тепловые и другие подсистемы взаимосвязаны.</p>
<h3 id="уровень-ii-каскад-потерь">3.2. Уровень II — Каскад потерь</h3>
<p>Пусть эффективность следующего преобразователя зависит от состояния предыдущего:</p>
<p>η_{k+1} = f(η_k, T_k, Δ_k, R_k)</p>
<p>E_{k+1} = η_k(X_k) · E_k</p>
<p>Пример: η₁ = 0.9, η₂ = 0.8, η₃ = 0.95 → η_total = 0.684. Из 100 единиц остаётся 68.4. Но в USA-слое каждый шаг зависит от полного состояния X_k, а не только от η_k.</p>
<h3 id="уровень-iii-каскад-усиления-потерь">3.3. Уровень III — Каскад усиления потерь</h3>
<p>Непосредственная связь с USA cascade factor:</p>
<p><strong>M_Z = ∏_{k=1}^{Z} (1 + q_k)</strong></p>
<p>Первоначальная потеря δE_0 вызывает изменение следующего элемента:</p>
<p>δE_1 = L_1 · δE_0</p>
<p>δE_2 = L_2 · L_1 · δE_0</p>
<p><strong>δE_Z = M_Z · δE_0</strong></p>
<p>где M_Z = L_Z · L_{Z-1} · ⋯ · L_1.</p>
<p>USA-каскад становится инструментом анализа устойчивости энергетической системы.</p>
<h3 id="уровень-iv-каскадные-отказы-энергосистем">3.4. Уровень IV — Каскадные отказы энергосистем</h3>
<p>Классическая проблема каскадных отказов:</p>
<p>отказ линии → перераспределение мощности → перегрузка другой линии → новое отключение → ещё большее перераспределение</p>
<p>USA предлагает универсальный язык измерения каскадности:</p>
<p>q_k = воздействие следующего этапа / устойчивый запас системы</p>
<p><strong>M_USA = ∏_k (1 + q_k)</strong></p>

<h3 id="уровень-v-рекурсивная-энергетика">3.5. Уровень V — Рекурсивная энергетика</h3>
<p>Здесь USA становится существенно отличимым от обычного каскада.</p>
<p>Обычный каскад: X_{k+1} = Φ(X_k) — оператор фиксирован.</p>
<p><strong>USA: X_{k+1} = Φ_k(X_k), а затем:</strong></p>
<p><strong>Φ_{k+1} = G(Φ_k, X_k)</strong></p>
<p>Сама энергетическая система учится на собственном состоянии. Например: нагрузка → перераспределение → измерение → изменение контроллера → новое распределение.</p>
<p>Современные энергетические системы действительно используют многоуровневые каскадные контроллеры и последовательные уровни управления. USA исследует именно изменение самого оператора управления.</p>
<h3 id="энергетическая-репка">3.6. Энергетическая «Репка»</h3>
<p>Энергосистема как граф G = (V, E): генерация, батареи, линии, преобразователи, потребители, резерв, контроллеры.</p>
<p>Один элемент может быть маленьким по мощности, но его включение может изменить связность системы:</p>
<p>ΔV_i = V(S ∪ {i}) − V(S)</p>
<p>Маленький компонент способен иметь огромную маржинальную роль, если система находится около критической границы. Это похоже на сказку «Репка»: маленький участник не обязательно обладает большой силой; он может быть тем узлом, который переводит систему через порог.</p>
<p><em>Для энергосетей это потенциально очень практичная идея.</em></p>

</div><h3 id="критерий-успеха">5.3. Критерий успеха</h3>
<p>USA-каскад считается информативным, если:</p>
<p>• M_USA предсказывает каскадные отказы раньше, чем классический contingency score;</p>
<p>• Λ_cas коррелирует с масштабом распространения возмущения;</p>
<p>• Метакаскад (Φ_{k+1} ≠ Φ_k) обнаруживает адаптивные контроллеры, которые меняют правила в процессе отказа.</p>
<h3 id="критерий-неудачи">5.4. Критерий неудачи</h3>
<p>USA-каскад не добавляет информации, если:</p>
<p>• M_USA просто воспроизводит contingency score с переобозначениями;</p>
<p>• q_k — монотонная функция классической перегрузки (тогда USA — репараметризация);</p>
<p>• Метакаскад не обнаруживается ни в одном реальном событии.</p>
