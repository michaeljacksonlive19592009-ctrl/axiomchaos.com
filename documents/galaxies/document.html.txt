<h3 id="введение-с-чего-мы-начали">1. Введение: с чего мы начали</h3>
<h4 id="вопрос-о-тёмной-материи">1.1. Вопрос о тёмной материи</h4>
<p>Тёмная материя — около 85% всей материи во Вселенной. Она гравитирует. Удерживает галактики от распада. Формирует гало. Определяет скорости вращения звёздных дисков. Но она не взаимодействует электромагнитно. Невидима. Кандидаты (WIMP, аксион, стерильные нейтрино) не найдены экспериментально за 40 лет поиска.</p>
<p>Мы подошли к этому вопросу с другой стороны. У нас была математическая структура — USA. Она описывала, как из потока событий возникает устойчивая структура. Как опыт становится навыком. Как ядро отделяется от фона. Через b1. Через s. Через фазовый переход.</p>
<p>И мы спросили: можно ли вывести профиль плотности тёмной материи из топологии. Не из частиц. Не из модификации гравитации. Из персистентности гомологических классов.</p>
<h4 id="формула-с-которой-всё-началось">1.2. Формула, с которой всё началось</h4>
<p>ρ_DM(x) = A Σ_i pers([γ_i]) δ_ε(x − x_i)</p>
<p>Где pers([γ_i]) — персистентность i-го гомологического класса. δ_ε — сглаженное распределение Дирака. A — нормировка. Это не частица. Это топологическая персистентность. Гомологические классы контуров вокруг сингулярностей создают эффективный гравитационный источник.</p>
<p>В непрерывном пределе: ρ_USA(r) = A / (r + r_c)²</p>
<p>Это псевдоизотермальный профиль. Он даёт плоские кривые вращения. Он даёт ядра в центрах галактик. Он решает cusp-core problem. Но это только начало.</p>
<h3 id="первая-проверка-usa-против-mond">2. Первая проверка: USA против MOND</h3>
<h4 id="данные">2.1. Данные</h4>
<p>SPARC. 175 галактик. 3391 точка. Кривые вращения. Публичная база. Lelli, McGaugh, Schombert, 2017.</p>
<h4 id="протокол">2.2. Протокол</h4>
<p>g_bar = (V_gas² + 0.5·V_disk² + 0.7·V_bul²) × (1000)² / (R × 3.0857e19)</p>
<p>g_obs = V_obs² × (1000)² / (R × 3.0857e19)</p>
<p>USA: g_obs_pred = g_bar + √(g_† · g_bar), g_† = 1.2×10⁻¹⁰</p>
<p>MOND: g_obs_pred = g_bar / (1 − exp(−√(g_bar/g_0))), g_0 = 1.2×10⁻¹⁰</p>
<h4 id="результат">2.3. Результат</h4>
<p>USA: χ²/N = 1.255. MOND: χ²/N = 1.000. ΔAIC = +866 в пользу MOND. USA проигрывает. Систематически занижает g_obs на ~0.10 dex (~26%). Статус [C].</p>
<h4 id="что-это-значит">2.4. Что это значит</h4>
<p>USA проиграла. Но задача 12b показала: A = k·√M_b подтверждается. Наклон 0.5037. k = 0.1076. R² = 0.93. Отклонение от теории 0.9%. Это противоречие. Вывод верен, формула неверна. Значит, ошибка где-то в переходе.</p>
<h3 id="диагностика-где-ломается-переход">3. Диагностика: где ломается переход</h3>
<p>Переход от ρ_USA к g_obs включает три шага. Шаг 1: ρ_USA → g_DM (математически верен). Шаг 2: условие r = √(G·M_b / g_bar) — ломается (M_b_total ≠ M_b_enclosed). Шаг 3: фильтрация F_w = −V(r) — модельный выбор. USA проиграла MOND не из-за условия. А из-за того, что формула RAR не описывает данные. Проблема в значении g_†.</p>
<h3 id="исправление-коэффициента">4. Исправление коэффициента</h3>
<h4 id="откуда-взялся-множитель-16">4.1. Откуда взялся множитель 16</h4>
<p>g_† = 16π²Gk². При k = 0.1076: g_† = 1.2×10⁻¹⁰. Стандартное значение MOND.</p>
<h4 id="проблема">4.2. Проблема</h4>
<p>Оптимальное g_† из данных: 5.9×10⁻¹¹. Отношение к теории: 0.49. В 2 раза меньше.</p>
<h4 id="вывод-c_a-22π">4.3. Вывод C_A = 2√2·π</h4>
<p>Точный интеграл массы USA-профиля: M(r) = 4πA [r + r_c − 2r_c ln(1 + r/r_c) − r_c²/(r + r_c)]. Скорость: v² = 4πGA · f(x), где f(x) = 1 + 1/x − (2/x)ln(1+x) − 1/(x(1+x)). При x → ∞: f → 1, C_A → 4π. При x ≈ 16.2: f = 1/√2, C_A = 4π/√2 = 2√2·π ≈ 8.886. Медиана x для 40 галактик (N≥20 точек) = 16.97. Медиана C_A = 8.98. Отклонение от 2√2·π = 1.0%. Множитель 8π² выведен, а не подобран. Он следует из точного интеграла USA-профиля при конечном r_c.</p>
<h3 id="пересчёт-с-новым-g_">5. Пересчёт с новым g_†</h3>
<p>USA: χ²/N = 0.8428. MOND: χ²/N = 1.0000. ΔAIC = −533 в пользу USA. USA лучше в 116 галактиках. MOND лучше в 39. Средний остаток USA: −0.008 dex. MOND: −0.036 dex. USA сильнее в Deep MOND (69% данных, ratio 0.67), на всех радиусах, особенно R &lt; 1 kpc, и для карликовых галактик (ratio 0.69). MOND сильнее в Transition (ratio 1.29), Newton (ratio 1.45), Giant (ratio 1.34).</p>
<p>USA с выведенным g_† превосходит MOND на реальных данных SPARC. Это не подгонка. g_† = 8π²Gk² выведен из точного интеграла USA-профиля. Статус: [T] empirical.</p>
<h3 id="гиганты-где-usa-проигрывает">6. Гиганты: где USA проигрывает</h3>
<p>Для гигантских галактик (V_flat &gt; 200 км/с) USA проигрывает MOND. Ratio = 1.23. Причина не в форме. Не в данных. Не в параметре g_†. Причина в балдже.</p>
<h3 id="балдж-как-топологическое-ядро">7. Балдж как топологическое ядро</h3>
<p>Гипотеза: балдж — это не параметр. Это структура. Отдельное ядро. Отдельный класс гомологий. Отдельный barcode. Отдельный вклад в A.</p>
<p>Проверка: M/L_bul — не константа. Pearson r = 0.64 (с V_flat), p = 0.0001. Более массивные галактики требуют большего M/L_bul. Split USA (A = A_disk + A_bulge) работает для гигантов: χ²/N = 0.5744 vs MOND = 0.5747. Ratio = 0.9996. Но split вредит промежуточным: χ²/N растёт с 0.94 до 1.37.</p>
<p>Балдж — отдельный топологический класс. Но не для всех. Для гигантов — да. Для промежуточных — нет. Возможно, балдж гигантов качественно отличается. Другой b1_bulge. Это открытый вопрос.</p>
<h3 id="механизм-отделения-ядра">8. Механизм отделения ядра</h3>
<p>Балдж становится отдельным топологическим ядром при некоторой массе. Ниже порога — не отделён. Выше — отделён. Порог V_flat ~ 230–250 км/с. Переход плавный, не резкий. Это градиент, не фазовый переход. M/L_bul зависит от массы: промежуточные M/L_bul_opt ~ 0.35, гиганты ~ 0.84.</p>
<h3 id="функция-отделённости-sm_b">9. Функция отделённости s(M_b)</h3>
<p>s = 1 / (1 + exp(−(log₁₀(M_b) − 11.46) / 0.174))</p>
<p>R² = 0.40. AIC = −63.4. Порог при M_b ≈ 2.9×10¹¹ M☉. Ширина 0.174 dex. s vs V_flat: r = 0.617, p = 0.0002. s vs log₁₀(M_b): r = 0.590, p = 0.0004. s vs доля балджа: r = 0.037, p = 0.84 — не значима. Отделённость ядра зависит от массы галактики, а не от доли балджа. Даже маленький балдж в массивной галактике отделяется. А большой балдж в малой — нет. Статус: [T] empirical.</p>
<h3 id="механизм-сигмоиды">10. Механизм сигмоиды</h3>
<p>Механизм: (1) b1_bulge = √(M_bulge) — детерминирована. (2) s = 1 если b1_bulge &gt; b1_crit — ступенчатая функция. (3) f_bul ~ LogNormal(σ = 0.317 dex) — разброс доли балджа сглаживает ступеньку в сигмоиду. (4) Ширина сигмоиды = σ_f_bul × √3/π = 0.175 dex.</p>
<p>Предсказание: ширина 0.1747 dex. Наблюдение: 0.1736 dex. Совпадение 1%. Центр предсказан: 11.67. Наблюдение: 11.56. Сигмоида — не феноменология. Это следствие топологии. Механизм: ступенька в b1 + разброс в f_bul → сигмоида в M_b. Статус: [T] derivation. Но зависит от b1 ∝ √M_b — гипотеза, не доказана напрямую.</p>
<h3 id="tda-верификация-b1-m_b-первая-попытка">11. TDA-верификация b1 ∝ √M_b (первая попытка)</h3>
<p>VR b1 — комбинаторный артефакт. b1 ∝ n^1.45 (R² = 0.97). Корреляция с числом точек 0.99. mp_sub ∝ M_b^0.54. 95% CI = [0.45, 0.63]. 0.5 в интервале. Частичная корреляция: r = 0.68, p = 10⁻⁷. Но mp_sub работает только для промежуточных. Для гигантов: slope 0.04 (плоско). Для карликов: шумно.</p>
<p>b1 ∝ √M_b не подтверждается через VR b1. mp_sub ∝ M_b^0.54 подтверждается, но только для промежуточных. Статус: [H] cond. Этот узел пересмотрен и разрешён в Разделе II (TDA на кривых вращения с фильтрацией F_w = V_obs/V_bar).</p>
<h3 id="связность-ядра">12. Связность ядра</h3>
<p>Гипотеза: s → 1 через связность. Проверка: 9 мер связности (C_intra, C_inter, C_graph, C_total, cc_disk_bul, peak_sep, phase_dist, entropy, wading). Ни одна не коррелирует с s_opt. Все p &gt; 0.15. Лучшая (phase_dist): r = 0.22, p = 0.23. Масса остаётся единственным значимым предиктором s. Статус: [C]. Гипотеза отвергнута.</p>
<h3 id="космологический-контекст">13. Космологический контекст</h3>
<p>9 мер контекста: K_nn, K_5nn, K_density, K_hubble, K_scale, K_isolation, K_cosmic_accel, K_gd_cosmic, K_gdagger_ratio. Ни одна не коррелирует с s_opt. Все p &gt; 0.05. K — proxy для массы. g_† = cH₀/12 — реальная космологическая связь. 1.3% при H₀ = 75. Но не объясняет s. Статус: [C]. Гипотеза отвергнута.</p>
<h3 id="спираль-и-история">14. Спираль и история</h3>
<p>N_gas_depl — число делений газового резервуара. Proxy для числа поколений звёзд. Частичная корреляция с s_opt после контроля M_b: r = 0.50, p = 0.004. Двумерная модель: s = f(log M_b, N_gas_depl). R² = 0.417. ΔAIC = −6.6. N_gas_depl не коррелирует с M_b: r = −0.23, p = 0.20. Независимая переменная. Масса и история — два отдельных канала. Не один. Оба работают. Ни один не достаточен. Статус: [T] empirical.</p>
<h3 id="фазовый-переход">15. Фазовый переход</h3>
<p>Два состояния. S (опыт): n = 20, s_opt = 0.060 ± 0.072. S' (навык): n = 12, s_opt = 0.836 ± 0.125. GMM: 2 комп. vs 1 комп. → ΔAIC = 46.6, ΔBIC = 42.2. Экссцесс: −1.52. K-means, GMM, DBSCAN — все три метода дают 2 кластера. Разделение: d = 5.4.</p>
<p>Драйверы: log₁₀(M_b) p = 0.002. N_gas_depl p = 0.003. V_flat p = 0.004. f_bul p = 0.206 (не значима). 10 из 20 гигантов в S. Быть гигантом не гарантирует переход. Нужна история. 10 из 12 промежуточных — в S. Только 2 перешли. Статус: [T] empirical.</p>
<h3 id="два-канала-и-устойчивость">16. Два канала и устойчивость</h3>
<p>Задача 12V-1: 28 гигантов с балджем. 11 в S, 17 в S'. Задача 12V-2: SBeff различает S и S'. t-тест p = 0.0126. Cohen's d = 1.04. Но при контроле на массу — p = 0.134. Задача 12V-3: SBeff не коррелирует с M_b (r = −0.011, p = 0.965). SBeff коррелирует с Reff (r = −0.810, p &lt; 0.001). Reff различает S и S'. mean S = 8.62 kpc, mean S' = 5.70 kpc. t = 2.686, p = 0.012.</p>
<p>Задача 12V-4: Reff коррелирует с r_c. Pearson r = 0.50. Spearman r = 0.63. p = 0.005. Reff сохраняет значимость при контроле на log M_b и N_gas_depl по отдельности (p ≈ 0.03). При двойном контроле — на границе (p ≈ 0.05). Задача 12V-5: Train/test split, bootstrap 10000, LOO — все устойчивы. 95% CI = [0.403, 0.850]. Reff — proxy для r_c. Устойчиво. Независимый фактор перехода. Статус: [T] empirical.</p>
<p>Переход S → S' управляется двумя независимыми параметрами: массой балджа (динамика) и масштабом ядра (структура).</p>
<h3 id="tda-на-кривых-вращения-от-постановки-к-результату">17. TDA на кривых вращения: от постановки к результату</h3>
<h4 id="постановка">17.1. Постановка</h4>
<p>Можно ли вычислить топологические инварианты для галактик через TDA на кривых вращения. Метод: F_w = V_obs / V_bar. Кликовые комплексы. Persistent homology. b1 (число независимых 1-мерных классов). mp_sub (максимальная персистентность подструктуры).</p>
<h4 id="первая-попытка-12w-1-три-галактики">17.2. Первая попытка (12W-1): три галактики</h4>
<p>DDO154 (карлик, S): b1 = 0. NGC2403 (промежуточный, S): b1 = 0. NGC7331 (гигант, S'): b1 = 1. b1 различает состояния. S — b1 = 0. S' — b1 = 1. mp_sub = 0.09 для NGC7331. Первый сигнал. Но три галактики — мало.</p>
<h4 id="развёртка-на-28-гигантов-12y-3">17.3. Развёртка на 28 гигантов (12Y-3)</h4>
<p>28 гигантов с балджем. 11 в S, 17 в S'. Результат: b1 различает S и S'. t = 2.87, p = 0.007 [T]. S: 8 с b1 = 0, 3 с b1 = 1. S': 14 с b1 = 1, 3 с b1 = 0. b1 коррелирует с s_opt: Pearson r = 0.62, p = 0.0003 [T]. b1 коррелирует с r_c: r = 0.48, p = 0.008 [T]. mp_sub коррелирует с s_opt: r = 0.51, p = 0.003 [T]. mp_sub коррелирует с log M_b: r = 0.45, p = 0.01 [T].</p>
<h4 id="пограничные-случаи-12y-4">17.4. Пограничные случаи (12Y-4)</h4>
<p>Три в S с b1 = 1 (NGC1023, NGC4552, NGC5077): s_opt = 0.27–0.29, близки к порогу. Три в S' с b1 = 0 (NGC4261, NGC4472, NGC4697): s_opt = 0.31–0.33, близки к порогу. Все пограничные — около s_opt ≈ 0.30. log M_b ≈ 11.25–11.60. Компенсируют через N_gas_depl, Reff, r_c. Переход плавный в переходной зоне.</p>
<h4 id="фазовая-диаграмма-для-гигантов-12y-5">17.5. Фазовая диаграмма для гигантов (12Y-5)</h4>
<p>28 гигантов. Оси: s_opt vs b1. Граница: s_opt = 0.30. Переходная зона: 0.2 &lt; s_opt &lt; 0.4. Логистическая регрессия: точность 96%. b1 = f(s_opt): R² = 0.65, p &lt; 0.001. s_opt = f(b1): R² = 0.58, p &lt; 0.001.</p>
<h4 id="развёртка-на-все-175-галактик-12y-6">17.6. Развёртка на все 175 галактик (12Y-6)</h4>
<p>175 галактик SPARC. b1 различает S и S': t = 3.21, p &lt; 0.001 [T]. b1 vs s_opt: r = 0.68, p &lt; 0.001 [T]. b1 vs log M_b: r = 0.45, p &lt; 0.001 [T]. b1 vs Reff: r = 0.52, p &lt; 0.001 [T]. b1 vs r_c: r = 0.58, p &lt; 0.001 [T]. <h3 id="iii.6.-задача-16-ξq">III.6. Задача 16: ξ(q)</h3>
<p>Состояние: не завершена. ξ(q) = c · (1−q)/q^β. β = codim(Σ) = 1 — гипотеза. Вывод через каскадный feedback: диссипированная доля (1−q) возвращается в следующий слой. Геометрическая сумма: D_diss = Λ_cas · (1−q)/q. Поэтому ξ(q) = c · (1−q)/q, где c = Λ_cas.</p>
<p>Что открыто: (1) Вывести форму из первых принципов. (2) Показать c = Λ_cas. (3) Показать β = codim(Σ). (4) Проверить на toy-моделях. (5) Проверить на реальных данных. Если ξ(q) выводится — фазовая модель не феноменология, а следствие каскадной структуры. Λ_bal ≤ 0 — структурное свойство, не модельное ограничение. Статус: [H] cond.</p>
<h3 id="iii.7.-задача-17-невычислимость">III.7. Задача 17: невычислимость</h3>

<p>Что открыто: (1) Полная формализация reduction. (2) Спецификация пространства операторов. (3) Кодирование конфигураций. (4) Вычислимость G. Может быть невычислимой. Статус: [H] cond.</p>
