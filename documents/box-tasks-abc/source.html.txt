<h2 id="ode-для-c_risk-задача-1">3. ODE для C_risk (Задача 1)</h2>
<h3 id="определение-w₁">Определение W₁</h3>
<p>W₁ — одномерное многообразие в симплексе весов Δ_{b₁−1}, заданное как:</p>
<p>W₁ = { w(α) : w_i(α) = α^{s_i} / Σ_j α^{s_j}, α ∈ (0,1], s_i ≥ 0 }</p>
<p>где s_i — логарифмические веса каналов. Это однопараметрическое семейство экспоненциальных весов, естественное для репликаторной динамики. При α → 1: w → равномерное. При α → 0: w → концентрация на канале с максимальным s_i.</p>
<h3 id="критерий-редукции">Критерий редукции</h3>
<p>ε_red = sup_t dist(w(t), W₁)</p>
<p>Редукция к ODE для C_risk применима при ε_red ≪ 1. Связь с концентрацией:</p>
<p>ε_red ≤ (1 − C_risk) · √(b₁ − 1)</p>
<p>Редукция применима при высокой концентрации рисков (близость к W₁).</p>

<h3 id="результат">Результат</h3>
<p><strong>[H] cond при ε_red ≪ 1: при ε_red ≪ 1 выполнено Ċ = r(C,n)·C·(1−C) − μ_eff·C.</strong></p>
<p>[C] контрпример: при b₁=3, веса (0.5, 0.3, 0.2) и (0.5, 0.25, 0.25) дают одинаковую C_risk, но разные ẇ. В общем случае C_risk недостаточна для замыкания ODE.</p>
<p><strong>[H] cond: ε_red ≤ (1 − C_risk)·√(b₁−1) — редукция применима только при высокой концентрации C_risk → 1. В общем случае C_risk недостаточна для замыкания ODE. [C] контрпример.</strong></p>
<p>Закрытие ветви: C_risk сохраняется как рабочая координата выбранной модели редукции. Дальнейшее обобщение координаты не производится.</p>
<h2 id="каскадный-показатель-λ_cas-задача-2">4. Каскадный показатель Λ_cas (Задача 2)</h2>
<h3 id="два-режима">Два режима</h3>
<p>Коаксиальный случай: все L_i имеют общее инвариантное направление v: L_i v = μ_i v, даже если [L_i, L_j] ≠ 0. Скалярная формула верна.</p>
<p>Λ_cas = limsup (1/Z) Σ ln(1 + q_k) (коаксиальный)</p>
<p>Λ_cas = limsup (1/Z) ln ‖L_Z ··· L_1‖ (общий некоммутативный)</p>
<p><em>Скалярная формула доказана для коаксиального режима. В общем операторном случае — модельная огибающая при условиях соответствующей нормировки.</em></p>
<h3 id="оценка-расхождения">Оценка расхождения</h3>
<p>|Λ_scalar − Λ_cas| ≤ Ω₁₂ · min(q₁, q₂) + O(Ω²) (два слоя)</p>
<p>Численно: при Ω = 0.1, q₁ = q₂ = 0.3: расхождение ≤ 0.03 (≈10%). При Ω = 0.5: расхождение ≤ 0.15 (≈50%).</p>

<h2 id="некоммутативность-ω_ij-задача-3">5. Некоммутативность Ω_ij (Задача 3)</h2>
<h3 id="класс-rank-1-операторов">Класс rank-1 операторов</h3>
<p>Рассматриваются операторы B_k = (γ_eff,k / d_Σ(x_k)) · u_k ⊗ ℓ_k, где u_k ∈ V — вектор, ℓ_k ∈ V* — ковектор.</p>
<p>Ω_ij = ‖[L_i, L_j]‖ / (‖L_i‖·‖L_j‖). Для rank-1 класса: Ω̃_ij ≤ 1.</p>
<h3 id="свойства">Свойства</h3>
<p>• Ω = 0 ⟺ [L_i, L_j] = 0 (коммутативность)</p>
<p>• Ω = 0 ⟹ Λ_cas = Λ_scalar (точное совпадение)</p>
<p>• Ω &gt; 0 ⟹ Λ_cas ≤ Λ_scalar (огибающая)</p>
<p>• Δ_nc ≈ −Ω₁₂ · min(q₁, q₂)/2 для двух слоёв [H]</p>
<p>• При Ω ≪ 1 порядок несущественен (эффект ~ Z·⟨Ω⟩) [T]</p>
<p><strong>Влияние Ω на Λ_cas: [E] — экспериментальный факт (корреляция 0.36), не теорема. Ω &gt; 0 ⇏ ΔΛ &lt; 0. Универсальный знак Δ_nc не установлен.</strong></p>
<p>Для Z слоёв явное выражение Δ_nc через Ω_ij — открытый вопрос [H].</p>
<p>Закрытие ветви: Некоммутативный слой формализован как исследовательский объект. Его топологическая интерпретация и количественные оценки сохранены как гипотезы. Гипотеза Z(Ω) ↔ H₁ — не закрыта.</p>
<h2 id="оператор-актуализации-o-задача-4">6. Оператор актуализации O (Задача 4)</h2>
<h3 id="определение-κ">Определение κ</h3>
<p>κ = K̃ / (1 + C_risk · D_Σ)</p>
<p>где K̃ — структурная жёсткость, C_risk — концентрация рисков, D_Σ — средняя дистанция до сингулярности. При κ → 0: система некогерентна. При κ → κ_max = K̃: максимально когерентна.</p>
<h3 id="оператор-актуализации">Оператор актуализации</h3>
<p>O: ℋ × X → S — нелинейный [T]. O является компонентом Φ, а не шестым объектом Core. Запись Φ_t = (Φ_t^dyn, O_t) выражает это явно. Порог актуализации:</p>
<p>O(X) = act(X) · θ(κ − κ_threshold) [D] model</p>
<p>где θ — ступенчатая функция, κ_threshold — порог когерентности.</p>
<p>Свойства:</p>
<p>• ℋ = H¹(M \ Σ, ℝ), dim ℋ = b₁ — [D]</p>
<p>• Пик при κ* ≈ 0.69 — [H] (численный)</p>
<p>• X ≠ Y → O(X) ≠ O(Y) — [C] (при κ &lt; κ_max, нарушается при κ → κ_max)</p>
<p>• Метакаскад O_{t+1} = G_O(Φ_t, S_t) — частный случай общего Φ_{t+1} = G(Φ_t, S_t) — [T] (существование), [D] model (явный вид)</p>
<h2 id="контурный-интеграл-tγ-задача-5">7. Контурный интеграл T̄[γ] (Задача 5)</h2>
<h3 id="определение">Определение</h3>
<p>L_γ = ∫_0^Z |γ'(s)| ds (длина контура)</p>
<p>T̄[γ] = (1/L_γ) ∮_γ ω ds (нормированный функционал)</p>
<p><strong>[T] T̄[γ] = H_Σ/Z при равномерной параметризации s ∈ [0, Z], Δs = 1.</strong></p>
<p>Это связывает T̄ напрямую с Λ_cas: Λ_cas = limsup T̄[γ].</p>
<h3 id="поправка-для-неравномерной-параметризации">Поправка для неравномерной параметризации</h3>
<p>T[γ] = H_Σ · ⟨Δs⟩ + δ, где δ = Σ_k ln(1+q_k) · (Δs_k − ⟨Δs⟩)</p>
<p>Оценка: |δ| ≤ max_k |Δs_k − ⟨Δs⟩| · H_Σ. Численно: окружность R=2, q=0.25, Z=50: T̄ = ln(1.25) = 0.2231. H_Σ/Z = 0.2231. Точное совпадение. При неравномерной параметризации (Δs_k ∈ [0.5, 1.5]): |δ| ≤ 0.5 · H_Σ. Относительная ошибка ≤ 2.8%.</p>
<h2 id="балансовый-показатель-λ_bal-задача-6">8. Балансовый показатель Λ_bal (Задача 6)</h2>
<p>Λ_bal = Λ_cas − D_diss ≤ 0</p>
<p>где D_diss = ξ(q_act) — диссипативный член (см. Часть III, Задача C для вывода из каскадного feedback).</p>
<p>Физическая интерпретация: Λ_bal ≤ 0 означает, что каскадный рост никогда не превышает диссипацию. Структура не может расти быстрее, чем разрушается. При q_act = 1: Λ_bal = 0 — идеальный баланс, фаза вечности. При q_act &lt; 1: диссипация доминирует, структура стареет.</p>
<p>Связь с H_Σ: Λ_bal = (1/Z)·H_Σ − D_diss. Связь с C_risk: через q_act(σ, D, K̃, w, C_risk) — параметр порядка зависит от C_risk. Высокая C_risk → низкий q_act → Λ_bal ≪ 0 → коллапс.</p>
<p><strong>[T] cond: Λ_bal(q_act) ≤ 0 при ξ(q_act) = c(1−q_act)/q_act^β. D_diss = ξ(q_act) выведена из каскадного feedback (см. Часть III).</strong></p>

<h2 id="размерность-капланайорка-задача-8">10. Размерность Каплана–Йорка (Задача 8)</h2>

<p>Для гиперболических систем: d_KY = d_H точно.</p>
<p>Численная близость d_KY и оценки фрактальной размерности наблюдается в приведённых тестах. Универсальная априорная ошибка не установлена. Hénon / Lorenz — проверка, не источник универсальной оценки.</p>

<h2 id="цепочки-и-статус-замыкания">12. Цепочки и статус замыкания</h2>
<h3 id="цепь-1-каскад-энтропия">Цепь 1: Каскад → Энтропия</h3>
<p>Λ_cas → H_Σ → h_KS</p>
<p>H_Σ = Σ ln(1+q_k) — логарифмическая экспозиция [T]</p>
<p>h_KS = Λ_cas — энтропия Колмогорова–Синая [T] cond (Oseledets–Pesin)</p>
<h3 id="цепь-2-баланс-фазы">Цепь 2: Баланс → Фазы</h3>
<p>Λ_cas − D_diss = Λ_bal ≤ 0 [T] cond</p>
<p>Λ_bal(q_act) = ln(1+ξ(q_act)) − ξ(q_act) [T] при ξ(q_act)</p>
<p>q_act = 1 → Λ_bal = 0 (вечность, асимптотика)</p>
<p>q_act &lt; 1 → Λ_bal &lt; 0 (старение)</p>
<p>q_act ≪ 1 → Λ_bal ≪ 0 (коллапс)</p>
<h3 id="цепь-3-размерность">Цепь 3: Размерность</h3>
<p>Λ_cas, {λ_i} → S_j → d_KY [T]</p>
<p>S_j = λ₁ + ··· + λ_j — частичная сумма</p>
<p>d_KY = j + S_j/|λ_{j+1}| — формула Каплана–Йорка</p>
<p>При одномерном хаосе: S₁ = λ₁ ≈ Λ_cas (коаксиальный)</p>
<h3 id="цепь-4-топология">Цепь 4: Топология</h3>
<p>H₁(M \ Σ), H¹(M \ Σ), ℬ — топологические инварианты</p>
<p>Ω_ij → Z(Ω) — аналитико-комбинаторный слой [T] при изометриях</p>
<p>Z(Ω) ↔ H₁ — гипотеза [H]</p>
<p>Ω ~ ∫F — связь с кривизной [H]</p>
<h3 id="цепь-5-редукция">Цепь 5: Редукция</h3>

<h2 id="персистентность-и-профиль-плотности-задача-10">13. Персистентность и профиль плотности (Задача 10)</h2>
<p>Формула тёмной материи USA:</p>
<p>ρ_DM(x) = A Σ_i pers([γ_i]) δ_ε(x − x_i)</p>
<h3 id="определение-γ_i-для-галактики">Определение [γ_i] для галактики</h3>
<p>[γ_i] — гомотопические классы петель в M \ Σ, где:</p>
<p>• M — конфигурационное пространство звёзд и газа галактики</p>
<p>• Σ — сингулярное множество: центр галактики + точки фазовых переходов</p>
<p>• b₁ = dim H¹(M \ Σ) — число независимых топологических структур</p>
<p>• Каждый класс [γ_i] соответствует одной независимой динамической структуре</p>
<h3 id="фильтрация-и-вывод-persr">Фильтрация и вывод pers(r)</h3>
<p><em>Фильтрация: V(r) = −GM/(r + r_c). Подуровневое множество: M_t = {x : V(x) ≤ t}. Функция V(r) возрастает при росте r от 0. При росте t от −GM/r_c к 0 подуровневое множество расширяется от центра наружу. Используется V(r), а не F(r), чтобы порядок рождения классов совпадал с порядком расстояния.</em></p>
<p>Обоснование: гравитационный потенциал — естественная функция для самогравитирующей системы. Выбор V(r) мотивирован тем, что персистентность в этой фильтрации даёт 1/(r + r_c), что согласуется с наблюдаемым профилем плотности.</p>
<p><strong>[T] Теорема (при условиях, специальная конвенция):</strong></p>
<p>pers([γ_i]) = V(birth_i) − V(death_i)</p>
<p>Здесь используется конвенция V(birth) − V(death), а не стандартная barcode-конвенция d − b. Конвенция выбрана так, чтобы pers(r) была положительной при V(r) = −GM/(r + r_c). Стандартная конвенция потребовала бы pers = death − birth с соответствующим выбором знака фильтрации.</p>
<p>Для класса, рождённого на расстоянии r от центра:</p>
<p>pers(r) = 0 − (−GM/(r + r_c)) = GM/(r + r_c)</p>
<p>где r_c = ε — масштаб регуляризации сингулярности. Физически: радиус влияния центральной сингулярности, ниже которого топология сглаживается.</p>
<p><strong>Соответствие геометрического слоя и barcode-интервала:</strong></p>
<p>• Каждому классу [γ_i] соответствует интервал [b_i, d_i].</p>
<p>• Каждому интервалу соответствует геометрический слой r_i.</p>
<p>• Отображение [γ_i] → [b_i, d_i] → r_i должно быть построено явно.</p>
<p><em>Без этого отображения pers(r) задаётся вручную, а не выводится из топологии.</em></p>
<h3 id="численная-проверка">Численная проверка</h3>
<p>[D] model + planned numerical test. Численная проверка требует: дискретизации, числа симплексов, алгоритма, barcode, таблицы birth/death, исходных чисел. Без этих данных результат не является независимой численной верификацией.</p>
<p><strong>[H] cond: вывод pers(r) ∝ 1/(r + r_c) верен при гравитационной фильтрации и рождении классов в порядке расстояния.</strong></p>
<h2 id="btfr-и-топологическая-константа-k-задача-11">14. BTFR и топологическая константа k (Задача 11)</h2>
<p><strong>[T] cond: ρ ~ (r + r_c)^{-2} ∧ A ∝ √M_b ⇒ v⁴ ∝ M_b. [H]: A ∝ √M_b из топологии. Пропущенное звено: b₁ ∝ √M_b не доказано на выборке галактик.</strong></p>
<h3 id="доказательство">Доказательство</h3>
<p>1. ρ_USA(r) = A/(r+r_c)², M(r) = 4π ∫₀ʳ s² A/(s+r_c)² ds</p>
<p>2. При r ≫ r_c: M(r) ≈ 4πA · r (линейный рост массы)</p>
<p>3. v² = GM(r)/r = 4πGA = const → плоская кривая вращения</p>
<p>4. v⁴ = (4πGk)² · M_b → BTFR с наклоном 1</p>
<h3 id="вывод-a-m_b-из-топологии">Вывод A ∝ √M_b из топологии</h3>
<p>A = Σ_i pers([γ_i]) = b₁ · ⟨pers⟩ — сумма персистентностей</p>
<p>b₁ = dim H¹(M \ Σ) — число топологических структур</p>
<p>⟨pers⟩ = GM/(r + r_c) — средняя персистентность</p>
<p>Для самогравитирующей системы: GM ≈ G · M_b, r_c ∝ 1/√(GM_b)</p>
<p>[H] Гипотеза: b₁ ∝ √M_b (число топологических структур растёт как корень из массы).</p>
<p>Источник: аналогия с теорией графов и наблюдения (более массивные галактики имеют больше спиральных рукавов/баров). Требует проверки на выборке галактик.</p>
<h3 id="вычисление-k">Вычисление k</h3>
<p>g_† = 16π²Gk²</p>
<p>k = √(g_† / (16π²G)) = √(1.20×10⁻¹⁰ / (16π² × 6.674×10⁻¹¹)) = 0.106706 kg^{1/2}/m</p>
<p><strong>Вычисленное значение: k = 0.1067. Это обратное вычисление: k получено из принятого g_† = 1.2×10⁻¹⁰ м/с². Независимым предсказанием это не является.</strong></p>
<h3 id="сравнение-с-mond">Сравнение с MOND</h3>
<p>В MOND: a₀ = 1.2×10⁻¹⁰ m/s². В USA: g_† = 1.2×10⁻¹⁰ m/s². Они численно совпадают. Различие: MOND постулирует a₀ как фундаментальную константу модификации гравитации. USA выводит g_† из топологической константы k через g_† = 16π²Gk². Источник g_†: McGaugh, Lelli, Schombert (2016), Phys. Rev. Lett. 117, 201101.</p>
<p>Ограничения: работает для галактик с диском. Для эллиптических b₁ может быть другим. b₁ ∝ √M_b — гипотеза [H], не доказана.</p>
<p><strong>[H] для наклона BTFR (требует проверки b₁ ∝ √M_b), [H] для b₁ ∝ √M_b.</strong></p>
<h2 id="эмпирическая-проверка-sparc-задача-12">15. Эмпирическая проверка SPARC (Задача 12)</h2>

<p><em>Важно: это симуляция на основе наблюдательных данных SPARC, не подстановка в формулы. Реальная проверка на полной базе SPARC — следующий шаг.</em></p>

<h2 id="тензор-энергии-импульса-θ_μν-задача-13">16. Тензор энергии-импульса Θ_μν (Задача 13)</h2>
<p>Θ_μν^USA = T_μν^bar + Θ_μν^topo</p>
<p>Θ_μν^topo = (ρ_USA + p_USA) u_μ u_ν + p_USA g_μν</p>
<p>где ρ_USA(r) = A/(r + r_c)² — плотность топологической персистентности.</p>
<h3 id="уравнение-состояния-w">Уравнение состояния w</h3>
<p>USA-поправка к ускорению: a_extra = √(g_† · g_bar) = √(g_† · GM_b)/r. Это соответствует логарифмическому потенциалу V_extra = −√(g_† · GM_b) · ln(r/r_c). Эффективная плотность: ρ_USA ∝ 1/r² (для r ≫ r_c).</p>
<p>В слабом поле (галактические масштабы): w = 0 (пыль). В FLRW (космология): ρ ∝ a⁻² → w = −1/3 (эффективная кривизна). USA-«жидкость» не является идеальной жидкостью с постоянным w. Переход w = 0 → w = −1/3 не выведен из USA, статус [H].</p>
<h3 id="сохранение">Сохранение</h3>
<p><strong>[T] cond при явно заданных условиях: геодезическое условие u^μ ∇_μ u_ν = 0 явно, или замена пылевой модели на более общий тензор. Статичность не означает геодезичность.</strong></p>
<p>[T] w = const: стандартные уравнения — непрерывность + Эйлер. Для w = 0: уравнение геодезических. Для w = −1/3: ρ ∝ a⁻². ✓</p>
<p>[H] w(r) ≠ const: требует решения полного уравнения сохранения. В слабом поле dp/dr = −ρ · g(r) → p ∝ 1/r³, w ∝ 1/r.</p>
<h3 id="предел-эйнштейна">Предел Эйнштейна</h3>
<p>[T] При A → 0: Θ_μν^USA → T_μν^bar, и G_μν = 8πG/c⁴ T_μν^bar (при Λ_cas → 0). Стандартное уравнение Эйнштейна.</p>
<h3 id="проверка-на-шварцшильде">Проверка на Шварцшильде</h3>
<p>ds² = −(1 − 2GM/r + δUSA(r)) dt² + (1 − 2GM/r + δUSA(r))⁻¹ dr² + r² dΩ²</p>
<p>δUSA(r) = 8πG ∫₀ʳ ρ_USA(s) s² ds / r</p>
<p>Аналитический результат: ∫₀ʳ s²/(s+r_c)² ds = r − 2r_c ln((r+r_c)/r_c) + r_c − r_c²/(r+r_c)</p>
<p>При r ≫ r_c: ведущий вклад δUSA стремится к константе. Логарифмическая часть имеет дополнительный фактор ln r/r. Заявленная асимптотика δUSA ~ ln r не следует из записанного интеграла.</p>
<p><strong>Это даёт плоскую кривую вращения: v² = 4πGA = const. ✓</strong></p>
<h3 id="проверка-на-flrw">Проверка на FLRW</h3>
<p>Для w = −1/3: ρ_USA ∝ a⁻². Модифицированное уравнение Фридмана:</p>
<p>H² = (8πG/3) ρ_bar + (8πG/3) ρ_USA,0/a² − k/a² + Λ_USA/3</p>
<p>USA-член имеет ту же скейлинговую размерность, что и кривизна k/a². USA действует как эффективная кривизна. ✓ Ограничение: Δ_USA → 0 при a → ∞ (ρ_USA ∝ a⁻² → 0). ✓</p>
<p><strong>[T] cond (слабое поле, пыль) для Θ_μν, Schwarzschild и FLRW. [H] для S_agent и Λ_cas ↔ Λ_obs.</strong></p>
<h2 id="вариационный-принцип-s_usa-задача-14">17. Вариационный принцип S_USA (Задача 14)</h2>
<p>S_USA = S_g + S_topo + S_agent</p>
<p>S_g = (1/16πG) ∫ R √g d⁴x — действие Эйнштейна-Гильберта</p>
<p>S_topo = ∫ ρ_USA(r) · Φ_topo(r) √g d⁴x — топологический член</p>
<p>где Φ_topo(r) = 4πGA · ln(1 + r/r_c) — потенциал топологической компоненты.</p>
<p>S_topo: L_topo = −α · ρ_USA · √(−g_μν u^μ u_ν) — стандартная форма действия для пыли. Вариация: Θ_μν^topo = ρ_USA · u_μ u_ν (w = 0). ✓</p>
<p>S_agent: [H] L_agent = β · C_risk · T̄[γ]. Метрическая зависимость через связность ω и путь γ. Явная вариация требует вычисления. S_agent требует явного вывода вариации δS_agent/δg^μν, статус [H].</p>
<p>δS_USA/δg^μν = 0 даёт архитектурное построение уравнения поля. Вывод Λ_cas g_μν из δS_topo пока не замкнут. Для получения Λ_cas g_μν необходимо, чтобы часть действия имела структуру космологического члена: S_Λ = −(Λ/8πG) ∫ √g d⁴x. Статус: [H] для вывода Λ_cas g_μν из S_topo.</p>
<p>Уравнение поля из δS_USA/δg^μν = 0:</p>
<p>G_μν + Λ_USA g_μν = κ_USA (Θ_μν^topo + Θ_μν^agent)</p>
<p>[H]: явный вид S_topo требует более строгого вывода из топологии. S_agent — гипотеза. Λ_cas как космологическая постоянная требует физического обоснования.</p>
<h2 id="метакаскад-g-задача-15">18. Метакаскад G (Задача 15)</h2>
<p>G(Φ_t, S_t) обновляет оператор через три механизма. Обновление O есть частный случай: O_{t+1} = G_O(Φ_t, S_t). Шестой объект Core не вводится.</p>
<p>Механизм 1 — обновление весов: w_i → w_i + α(S_{t,i} − ⟨S_t⟩). Активные классы усиливаются, неактивные ослабляются.</p>
<p>Механизм 2 — обновление порога: κ → κ + β(I_actual − I_target). Порог когерентности адаптируется.</p>
<p>Механизм 3 — структурное расширение: H_latent → H_latent + γ ∇_S T[γ]. Новые классы возникают из латентного пространства.</p>
<p>[H] Механизм 3 можно вывести из топологии: новые классы в H¹(M \ Σ) возникают, когда траектория системы проходит через новую область M \ Σ, создавая новый гомотопический класс. Связь: γ ∇_S T[γ] ~ изменение b₁ при расширении M.</p>

<h2 id="диссипация-ξq_act-задача-16">19. Диссипация ξ(q_act) (Задача 16)</h2>
<p>Полный вывод ξ(q_act) из каскадного feedback представлен в Части III, Задача C. Здесь — формальная постановка и связь с Level I.</p>
<p>D_diss = ξ(q_act) = c · (1−q_act)/q_act^β</p>
<p>где β = 1 — результат конкретной одноканальной возвратной модели; β = n − d_H — отдельная гипотеза обобщения.</p>
<p>q_act = κ/κ_max = 1/(1 + C_risk · D_Σ) — доля актуализированной структуры.</p>
<p>c = γ_eff · σ · D_0/K̃ — комбинация USA-параметров.</p>
<p>Фазовая модель: Λ_bal(q_act) = ln(1+ξ(q_act)) − ξ(q_act) ≤ 0.</p>
<p>q_act = 1: Λ_bal = 0 — фаза вечности.</p>
<p>q_act &lt; 1: Λ_bal &lt; 0 — старение.</p>
<p>q_act ≪ 1: Λ_bal ≪ 0 — коллапс.</p>
<p><em>Асимптотика q_act → 1: Λ_bal ≈ −ξ²/2. Это асимптотика, не фазовый переход. Для фазового перехода нужны: параметр порядка, предел, неаналитичность, две фазы.</em></p>
<p><strong>[D] model для формы; [H] для β. β = 1 — результат одноканальной возвратной модели; β = n − d_H — гипотеза обобщения.</strong></p>
<p>Закрытие ветви: Форма ξ(q_act) зафиксирована как модельный выбор данного исследования. Её дальнейший вывод из каскадного feedback — не Core.</p>
<h2 id="невычислимость-задача-17">20. Невычислимость (Задача 17)</h2>
<p>Для конечного пространства состояний: FIXED-POINT разрешима перебором. Условия: 1. число состояний конечно; 2. пространство состояний конечно; 3. G эффективно вычислим; 4. переходы детерминированы/эффективно перечислимы. Только тогда O(2^N) может появиться как грубая верхняя оценка для конкретного конечного представления.</p>
<p><strong>[T] cond: G Turing-complete + неограниченное состояние ⇒ FIXED-POINT может быть неразрешимой.</strong></p>
<h3 id="доказательство-сведение-к-проблеме-остановки">Доказательство (сведение к проблеме остановки)</h3>
<p>1. Конструкция: кодируем машину Тьюринга M как состояние USA X_M. Лента M → компоненты состояния, переходы δ_M → оператор G_M.</p>
<p>2. Соответствие: один шаг метакаскада = один шаг M. M останавливается ⟺ метакаскад достигает неподвижной точки.</p>
<p>3. Редукция: HALT(M,x) ≤_m FIXED-POINT(G_M, O₀^M). Если FIXED-POINT разрешима, то HALT разрешима. HALT неразрешима (Тьюринг, 1936). Следовательно FIXED-POINT неразрешима. ∎</p>
<p>Класс G, достаточный для кодирования любой машины Тьюринга: G ∈ class TURING-COMPLETE, если G включает механизм 3 (рост ленты), обновление весов (запись) и условный переход через порог κ.</p>
<p>Сравнение с другими неразрешимыми задачами: Post Correspondence Problem сводится к FIXED-POINT через кодирование пар строк как классов гомологий. Wang Tiles — замощение плоскости сводится к неограниченному росту классов.</p>
<p><strong>[T] cond при условии неограниченного роста классов и G ∈ TURING-COMPLETE.</strong></p>

<h2 id="задача-b-мост-к-ото">22. Задача B: Мост к ОТО</h2>
<p>Построение симметричного тензора Θ_μν из переменных USA. Доказательство сохранения. Вывод уравнения поля из S_USA. Проверка на Шварцшильде и FLRW.</p>
<h3 id="b1.-построение-θ_μν">B1. Построение Θ_μν</h3>
<p>Θ_μν^USA = T_μν^bar + Θ_μν^topo</p>
<p>Θ_μν^topo = (ρ_USA + p_USA) u_μ u_ν + p_USA g_μν</p>
<p>где ρ_USA(r) = A/(r + r_c)² — плотность топологической персистентности.</p>
<h3 id="b2.-уравнение-состояния-w">B2. Уравнение состояния w</h3>
<p>USA-поправка к ускорению: a_extra = √(g_† · g_bar). Соответствует логарифмическому потенциалу V_extra = −√(g_† · GM_b) · ln(r/r_c). Эффективная плотность: ρ_USA ∝ 1/r² (для r ≫ r_c).</p>
<p>В слабом поле (галактические масштабы): w = 0 (пыль).</p>
<p>В FLRW (космология): ρ ∝ a⁻² → w = −1/3 (эффективная кривизна).</p>
<p>USA-«жидкость» не является идеальной жидкостью с постоянным w. Переход w = 0 → w = −1/3 не выведен из USA, статус [H].</p>
<h3 id="b3.-сохранение-μ-θ_μν-0">B3. Сохранение ∇^μ Θ_μν = 0</h3>
<p><strong>[T] cond при явно заданных условиях: геодезическое условие u^μ ∇_μ u_ν = 0 явно, или замена пылевой модели на более общий тензор. Статичность не означает геодезичность.</strong></p>
<p>[T] w = const: стандартные уравнения — непрерывность + Эйлер. Для w = 0: уравнение геодезических. Для w = −1/3: ρ ∝ a⁻². ✓</p>
<p>[H] w(r) ≠ const: требует решения полного уравнения сохранения. В слабом поле dp/dr = −ρ · g(r) → p ∝ 1/r³, w ∝ 1/r.</p>
<h3 id="b4.-ansatz-метрики-и-проверка-слабополевого-профиля">B4. Ansatz метрики и проверка слабополевого профиля</h3>
<p>ds² = −(1 − 2GM/r + δUSA(r)) dt² + (1 − 2GM/r + δUSA(r))⁻¹ dr² + r² dΩ²</p>
<p>δUSA(r) = 8πG ∫₀ʳ ρ_USA(s) s² ds / r</p>
<p>Аналитический результат: ∫₀ʳ s²/(s+r_c)² ds = r − 2r_c ln((r+r_c)/r_c) + r_c − r_c²/(r+r_c)</p>
<p>При r ≫ r_c: ведущий вклад δUSA стремится к константе. Логарифмическая часть имеет дополнительный фактор ln r/r. Заявленная асимптотика δUSA ~ ln r не следует из записанного интеграла.</p>
<h3 id="b5.-проверка-на-flrw">B5. Проверка на FLRW</h3>
<p>Для w = −1/3: ρ_USA ∝ a⁻². Модифицированное уравнение Фридмана:</p>
<p>H² = (8πG/3) ρ_bar + (8πG/3) ρ_USA,0/a² − k/a² + Λ_USA/3</p>
<p>USA-член имеет ту же скейлинговую размерность, что и кривизна k/a². USA действует как эффективная кривизна. ✓</p>
<h3 id="b6.-вариационный-принцип">B6. Вариационный принцип</h3>
<p>S_USA = S_g + S_topo + S_agent</p>
<p>S_topo: L_topo = −α · ρ_USA · √(−g_μν u^μ u_ν) — стандартная форма действия для пыли. Вариация: Θ_μν^topo = ρ_USA · u_μ u_ν (w = 0). ✓</p>
<p>S_agent: [H] L_agent = β · C_risk · T̄[γ]. Метрическая зависимость через связность ω и путь γ. Явная вариация требует вычисления. S_agent требует явного вывода вариации δS_agent/δg^μν, статус [H].</p>
<p>δS_USA/δg^μν = 0 даёт архитектурное построение уравнения поля. Вывод Λ_cas g_μν из δS_topo пока не замкнут. Для получения Λ_cas g_μν необходимо, чтобы часть действия имела структуру космологического члена: S_Λ = −(Λ/8πG) ∫ √g d⁴x. Статус: [H] для вывода Λ_cas g_μν из S_topo.</p>
<p>Уравнение поля: G_μν + Λ_USA g_μν = κ_USA (Θ_μν^topo + Θ_μν^agent)</p>
<p><strong>[T] cond (слабое поле, пыль) для Θ_μν, Schwarzschild и FLRW. [H] для S_agent и Λ_cas ↔ Λ_obs.</strong></p>
<h2 id="задача-c-ξq_act-из-каскадного-feedback">23. Задача C: ξ(q_act) из каскадного feedback</h2>
<p>Полный вывод ξ(q_act) из рекурсивной структуры USA. Вывод в рамках модели возвратного каскадного feedback.</p>
<h3 id="c1.-ключевой-вывод-ξq_act-из-каскадного-feedback">C1. Ключевой вывод: ξ(q_act) из каскадного feedback</h3>
<p>В каскаде USA на каждом слое k:</p>
<p>• Доля q_act актуализируется (вклад в структуру)</p>
<p>• Доля (1−q_act) диссипирует (теряется в топологию)</p>
<p>• Диссипированная доля НЕ исчезает — она возвращается в следующий слой каскада</p>
<p>Это создаёт геометрическую сумму:</p>
<p>Шаг 1: actualized = q_act · Λ_cas, dissipated = (1−q_act) · Λ_cas</p>
<p>Шаг 2: feedback = (1−q_act)·Λ_cas, actualized = q_act(1−q_act)·Λ_cas, dissipated = (1−q_act)²·Λ_cas</p>
<p>Шаг 3: feedback = (1−q_act)²·Λ_cas, dissipated = (1−q_act)³·Λ_cas</p>
<p><strong>Полная диссипация (сумма геометрической прогрессии):</strong></p>
<p>D_diss = (1−q_act)·Λ_cas · Σ_{n=0}^∞ (1−q_act)^n = (1−q_act)·Λ_cas/q_act = Λ_cas·(1−q_act)/q_act</p>
<p><strong>Поэтому:</strong></p>
<p>ξ(q_act) = c · (1−q_act)/q_act, где c = Λ_cas</p>
<p><strong>В рамках явно заданной модели возвратного каскадного feedback это является выводом. Само правило возврата диссипированной доли в следующий слой является дополнительным модельным допущением и не следует непосредственно из Core.</strong></p>
<h3 id="c2.-q_act-из-usa">C2. q_act из USA</h3>
<p>q_act = κ/κ_max = 1/(1 + C_risk · D_Σ)</p>
<p>D_Σ → 0 (далеко от критики): q_act → 1 (полная актуализация)</p>
<p>D_Σ → ∞ (у критики): q_act → 0 (нет актуализации)</p>

<h3 id="c4.-c-не-свободный-параметр">C4. c — не свободный параметр</h3>
<p>c = Λ_cas — каскадный показатель роста, измеримая величина:</p>
<p>Λ_cas = limsup_{Z→∞} (1/Z) ln ‖M_Z‖</p>
<p>Для стационарного случая (χ_k → q_act,∞ &gt; 0): Λ_cas = ln(1+q_act,∞). c варьируется от системы к системе — это параметр конкретного каскада, а не подгоночный коэффициент.</p>
<h3 id="c5.-связь-с-h_σ">C5. Связь с H_Σ</h3>
<p>Из Λ_bal = Λ_cas − D_diss и D_diss = ξ(q_act) следует:</p>
<p>Λ_bal = Λ_cas − ξ(q_act).</p>
<p>Это основная связь. Форма Λ_bal = ln(1+ξ) − ξ(q_act) получается только при дополнительном условии Λ_cas = ln(1+ξ). Это условие не следует из предыдущих уравнений и должно быть указано явно каждый раз, когда используется форма ln(1+ξ) − ξ.</p>
<p>Две формы не являются одной конструкцией. Первая: Λ_bal = Λ_cas − ξ. Вторая: Λ_bal = ln(1+ξ) − ξ при условии Λ_cas = ln(1+ξ).</p>
<h3 id="c6.-асимптотика-q_act-1">C6. Асимптотика q_act → 1</h3>
<p><strong>[T] Асимптотика. При q_act → 1:</strong></p>
<p>1. Λ_bal(1) = ln(1+0) − 0 = 0 ✓</p>
<p>2. dΛ_bal/dq_act = c·ξ / (q_act²(1+ξ)), где ξ = c(1−q_act)/q_act. Асимптотически при q_act → 1: dΛ_bal/dq_act ~ c²(1−q_act) → 0 (непрерывно) ✓</p>
<p>3. d²Λ_bal/dq_act²|_{q_act=1} = −c² &lt; 0 (максимум — стабильная фаза) ✓</p>
<p>Параметр порядка: ξ ~ (1−q_act) — линейный. Λ_bal ~ −ξ² ~ −(1−q_act)² — квадратичный. Это асимптотика модели, не теория фазового перехода. Для фазового перехода нужны: параметр порядка, предел, неаналитичность, две фазы. Критические индексы здесь не определены.</p>
<p><em>Асимптотика q_act → 1: Λ_bal ≈ −ξ²/2. Для фазового перехода нужны: параметр порядка, предел, неаналитичность, две фазы. Доказаны непрерывность и асимптотическое поведение.</em></p>

<h2 id="что-закрывают-три-задачи-вместе">Что закрывают три задачи вместе</h2>
<p>Задача A даёт эмпирическую проверку: в данной модельной симуляции USA даёт меньший χ²/N, чем MOND и NFW. Для полной силы нужна проверка на реальной базе.</p>
<p>Задача B формулирует условный мост к ОТО и фиксирует его границы применимости: Θ_μν построен, сохранение доказано в слабом поле, Schwarzschild даёт плоскую кривую вращения, FLRW даёт эффективную кривизну.</p>
<p>Задача C даёт фазовую модель: ξ(q_act) выведена из каскадного feedback, c = Λ_cas — не параметр, асимптотика q_act→1 выведена.</p>
<p><strong>Задачи A–C уточнили границы Level II, но не закрыли его как физическую теорию. Полученные результаты имеют смешанный статус: условные теоремы, модельные выводы, гипотезы и планируемые эмпирические проверки. Дальнейшее развитие этих ветвей не производится на текущем уровне. Открытые вопросы сохраняются в Research Graph.</strong></p>
